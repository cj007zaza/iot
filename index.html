$\mu$F Microfarad ไมโครฟารัด ($10^{-6}$ ฟารัด) บทที่ 06 หน่วยความจุที่พบบ่อยที่สุดในวงจรอิเล็กทรอนิกส์
A/D / ADC Analog-to-Digital Converter ตัวแปลงสัญญาณแอนะล็อกเป็นดิจิทัล บทที่ 09 วงจรแปลงแรงดันไฟฟ้าต่อเนื่องเป็นตัวเลข 10-bit (0-1023)
AC / VAC Alternating Current / Volts Alternating Current ไฟฟ้ากระแสสลับ / โวลต์กระแสสลับ บทที่ 06 ไฟฟ้าที่มีทิศทางและขนาดเปลี่ยนแปลงเป็นรูปคลื่นไซน์ เช่น ไฟฟ้าตามบ้าน 220V 50Hz
ADC / A/D Analog-to-Digital Converter ตัวแปลงสัญญาณแอนะล็อกเป็นดิจิทัล บทที่ 08 วงจรแปลงระดับแรงดันไฟฟ้าต่อเนื่อง (0-3.3V) ให้เป็นค่าตัวเลขดิจิทัล 10-bit (0-1023) หรือ 12-bit (0-4095)
AO Analog Output ขาเอาต์พุตแอนะล็อกของเซ็นเซอร์ บทที่ 09 ส่งระดับแรงดันไฟต่อเนื่องตามค่าทางกายภาพที่วัดได้
API Application Programming Interface ส่วนต่อประสานโปรแกรมประยุกต์ บทที่ 10 ช่องทางให้โปรแกรมภายนอกหรือหน้าเว็บดึงข้อมูลจาก Broker ไปแสดงผล
Ah Ampere-hour แอมแปร์-ชั่วโมง บทที่ 06 หน่วยวัดความจุพลังงานไฟฟ้าของแบตเตอรี่ (จ่ายกระแส 1 แอมแปร์ได้นานกี่ชั่วโมง)
Auth Token Authentication Token โทเคนยืนยันตัวตนความปลอดภัย บทที่ 05 สตริงตัวอักษรรหัสลับยาว 32 ตัวอักษร ทำหน้าที่เสมือนกุญแจส่วนตัวของอุปกรณ์ในการสื่อสารกับเซิร์ฟเวอร์
BLE Bluetooth Low Energy บลูทูธพลังงานต่ำ บทที่ 01 โปรโตคอลสื่อสารระยะสั้นกินไฟน้อยมาก เหมาะกับ Smart Wearable และเซ็นเซอร์พกพา
C Capacitor / Capacitance ตัวเก็บประจุ / ค่าความจุไฟฟ้า บทที่ 06 อุปกรณ์กักเก็บและคายประจุไฟฟ้า หน่วยวัดเป็น ฟารัด (Farad: F)
CCTV Closed-Circuit Television กล้องโทรทัศน์วงจรปิด บทที่ 01 ระบบส่งสัญญาณภาพจากกล้องไปยังจุดรับชมเฉพาะจุดเพื่อการรักษาความปลอดภัยและจราจร
COM Communication Port พอร์ตสื่อสารอนุกรมเสมือนบนระบบปฏิบัติการ บทที่ 07 เช่น COM3, COM4 ที่ Windows กำหนดให้กับบอร์ดที่เสียบ USB
DAC / D/A Digital-to-Analog Converter ตัวแปลงสัญญาณดิจิทัลเป็นแอนะล็อก บทที่ 08 วงจรสร้างแรงดันไฟฟ้าแอนะล็อกของจริงจากค่าตัวเลขดิจิทัล
DC / VDC Direct Current / Volts Direct Current ไฟฟ้ากระแสตรง / โวลต์กระแสตรง บทที่ 06 ไฟฟ้าที่มีทิศทางการไหลขั้วเดียวสม่ำเสมอ เช่น แบตเตอรี่ ถ่านไฟฉาย วงจรไมโครคอนโทรลเลอร์
DHT11 Digital Humidity and Temperature Sensor Model 11 เซ็นเซอร์วัดอุณหภูมิและความชื้นสัมพัทธ์แบบดิจิทัลรุ่น 11 บทที่ 09 เซ็นเซอร์ยอดนิยมส่งข้อมูลดิจิทัลทางสายเดี่ยว (Single-wire serial)
DO Digital Output ขาเอาต์พุตดิจิทัลของเซ็นเซอร์ บทที่ 09 ส่งลอจิก 0 หรือ 1 ตามเกณฑ์เปรียบเทียบแรงดันของชิป LM393
ESP32 Espressif Systems 32-bit Dual-core Microcontroller ไมโครคอนโทรลเลอร์ทรงพลัง 2 คอร์ พร้อม Wi-Fi และ Bluetooth ในตัว บทที่ 08 บอร์ดประมวลผลหลักที่ใช้ในการทดลองบทนี้ (NodeMCU ESP32 30/38 pins)
ESP8266 Espressif Systems SoC model 8266 ชิปประมวลผล 32-bit พร้อม Wi-Fi ในตัวของบริษัท Espressif บทที่ 07 หัวใจประมวลผลหลักของ NodeMCU ทำงานที่ความถี่ 80/160 MHz
Echo Echo ขาสัญญาณสะท้อนกลับ บทที่ 03 ขาเอาต์พุตของเซ็นเซอร์อัลตราโซนิก ส่งพัลส์ความยาวเวลาเท่ากับเวลาที่คลื่นเสียงสะท้อนกลับมา
F Farad ฟารัด บทที่ 06 หน่วยวัดความจุประจุไฟฟ้าตามระบบสากล SI
FSR Force Sensitive Resistor ตัวต้านทานแปรผันตามแรงกด บทที่ 02 แผ่นเซ็นเซอร์ที่ความต้านทานจะลดลงเมื่อมีแรงกดกระทำ
GND Ground กราวด์ / จุดอ้างอิงแรงดันศูนย์โวลต์ (0V) บทที่ 03 ขั้วลบของระบบไฟฟ้า วงจรจะทำงานได้ต้องต่อกราวด์ร่วมกัน
GPIO General-Purpose Input/Output ขาอินพุต/เอาต์พุตอเนกประสงค์ บทที่ 07 ขาพอร์ตดิจิทัลบนบอร์ด เช่น D0-D8 (GPIO16, GPIO5, GPIO4 ฯลฯ)
GPS Global Positioning System ระบบระบุพิกัดตำแหน่งบนโลกผ่านดาวเทียม บทที่ 01 ใช้ระบุละติจูดและลองจิจูดของอุปกรณ์ เช่น รถยนต์อัจฉริยะ โดรน หรือสมาร์ตโฟน
GUI Graphical User Interface ส่วนต่อประสานกราฟิกกับผู้ใช้ บทที่ 10 เช่น หน้าจอโปรแกรม MQTT Explorer ที่แสดง Topic Tree เป็นรูปภาพต้นไม้
I/O Input / Output สัญญาณขาเข้าและขาออก บทที่ 02 ช่องทางติดต่อสื่อสารระหว่างไมโครคอนโทรลเลอร์กับโลกภายนอก
IC Integrated Circuit วงจรรวม / วงจรเบ็ดเสร็จ (ไอซี) บทที่ 06 ชิปซิลิคอนขนาดเล็กที่รวมชิ้นส่วนวงจรอิเล็กทรอนิกส์หลายล้านตัวไว้ภายใน
ID Identification / Identifier รหัสระบุตัวตน บทที่ 05 เช่น Template ID สำหรับอ้างอิงแม่แบบอุปกรณ์ในระบบคลาวด์
IDE Integrated Development Environment สภาพแวดล้อมสำหรับการพัฒนาแบบเบ็ดเสร็จ บทที่ 02 โปรแกรมสำหรับเขียน ทดสอบ และคอมไพล์โค้ดโปรแกรม
IO / GPIO Input / Output / General-Purpose Input/Output ขาอินพุต/เอาต์พุตอเนกประสงค์ บทที่ 03 พอร์ตติดต่อของ KidBright เช่น ขา IO18 และ ขา IO19
IR Infrared รังสีอินฟราเรด บทที่ 02 คลื่นแม่เหล็กไฟฟ้าความยาวคลื่นยาวกว่าแสงสีแดง ใช้ในรีโมทและเซ็นเซอร์ตรวจจับวัตถุ
IoT Internet of Things อินเทอร์เน็ตของสรรพสิ่ง บทที่ 01 เครือข่ายของสิ่งของหรืออุปกรณ์ที่ฝังเซ็นเซอร์และซอฟต์แวร์ให้สามารถแลกเปลี่ยนข้อมูลกันผ่านอินเทอร์เน็ตได้อัตโนมัติ
JSON JavaScript Object Notation รูปแบบข้อมูลมาตรฐานที่ใช้ระบุลิงก์ Index ติดตั้งบอร์ด บทที่ 07 ไฟล์ package_esp8266com_index.json ที่ใส่ใน Preferences
KB KidBright บอร์ดสมองกลฝังตัวเพื่อการศึกษา พัฒนาโดย NECTEC ใช้ชิปหลัก ESP32 บทที่ 02 บอร์ดไมโครคอนโทรลเลอร์พร้อมหน้าจอ LED 16x8 ปุ่มกด ลำโพง และเซ็นเซอร์วัดแสง/อุณหภูมิในตัว
LDR Light Dependent Resistor ตัวต้านทานแปรค่าตามความเข้มแสง / โฟโตรีซิสเตอร์ บทที่ 09 สารกึ่งตัวนำ CdS ที่ความต้านทานจะลดลงเมื่อได้รับแสงสว่าง
LED Light-Emitting Diode ไดโอดเปล่งแสง บทที่ 02 อุปกรณ์ให้แสงสว่าง หน้าจอ Matrix 16x8 บน KidBright
LPG Liquefied Petroleum Gas ก๊าซปิโตรเลียมเหลว / ก๊าซหุงต้ม บทที่ 02 ก๊าซเชื้อเพลิงที่ประกอบด้วยโพรเพนและบิวเทน ไวไฟสูง
M2M Machine-to-Machine การสื่อสารระหว่างเครื่องจักรกับเครื่องจักร บทที่ 01 การแลกเปลี่ยนข้อมูลโดยตรงระหว่างอุปกรณ์ปลายทางโดยไม่มีมนุษย์เข้ามาแทรกแซง
MCU Microcontroller Unit หน่วยควบคุมขนาดเล็ก / ไมโครคอนโทรลเลอร์ บทที่ 01 ไอซีที่รวม CPU, RAM, ROM, I/O ไว้ในตัว เช่น ESP32, ESP8266, Arduino
MQTT Message Queuing Telemetry Transport โปรโตคอลการสื่อสารข้อมูลระยะไกลแบบส่งต่อข้อความ (สถาปัตยกรรม Publish/Subscribe) บทที่ 10 โปรโตคอลมาตรฐานสากลสำหรับ IoT น้ำหนักเบามาก กินแบนด์วิดท์ต่ำ ออกแบบโดย Andy Stanford-Clark และ Arlen Nipper
NC Normally Closed หน้าสัมผัสปกติปิด บทที่ 09 สภาวะปกติวงจรปิด (ไฟไหลผ่านตลอด) เมื่อรีเลย์ทำงานหน้าสัมผัสจะถูกดึงแยกออก วงจรจะถูกตัดขาด
NECTEC National Electronics and Computer Technology Center ศูนย์เทคโนโลยีอิเล็กทรอนิกส์และคอมพิวเตอร์แห่งชาติ บทที่ 02 หน่วยงานวิจัยและพัฒนาของไทยผู้ให้กำเนิดบอร์ด KidBright
NFC Near Field Communication การสื่อสารไร้สายระยะใกล้มาก บทที่ 01 ระยะ 4-10 ซม. ใช้ในการแตะจ่ายเงินหรือจับคู่อุปกรณ์อย่างรวดเร็ว
NO Normally Open หน้าสัมผัสปกติเปิด บทที่ 09 สภาวะปกติวงจรเปิด (ไฟไม่ผ่าน) เมื่อรีเลย์ทำงานหน้าสัมผัสจะดูดติดกัน ไฟจึงจะไหลผ่าน
NodeMCU Node Microcontroller Unit บอร์ดพัฒนาอุปกรณ์ IoT ตระกูล ESP8266 แบบ Open-source บทที่ 07 บอร์ดพัฒนาที่รวบรวมชิป ESP8266, ภาคจ่ายไฟ 3.3V, และชิปแปลง USB-to-UART ไว้บนบอร์ดเดียว
OS Operating System ระบบปฏิบัติการ บทที่ 01 ซอฟต์แวร์ระบบ เช่น Linux, Windows, RTOS ที่ใช้จัดการทรัพยากรของอุปกรณ์
PIR Passive Infrared Sensor เซ็นเซอร์ตรวจจับรังสีอินฟราเรดจากความร้อนของสิ่งมีชีวิต บทที่ 02 ใช้ตรวจจับคนหรือสัตว์ที่เดินผ่านในระยะ 3-7 เมตร
PWM Pulse Width Modulation การมอดูเลตความกว้างสัญญาณพัลส์ บทที่ 08 เทคนิคการเปิด-ปิดสัญญาณดิจิทัลอย่างรวดเร็วเพื่อจำลองระดับแรงดันแอนะล็อก เช่น หรี่ไฟ LED
QoS Quality of Service ระดับการรับประกันคุณภาพในการส่งมอบข้อความ บทที่ 10 กลไกใน MQTT ที่กำหนดความน่าเชื่อถือของการส่งข้อมูล มี 3 ระดับ (QoS 0, QoS 1, QoS 2)
R Resistor / Resistance ตัวต้านทาน / ค่าความต้านทานไฟฟ้า บทที่ 06 อุปกรณ์จำกัดปริมาณกระแสไฟฟ้า หน่วยวัดเป็น โอห์ม (Ohm: $\Omega$)
RF Radio Frequency ความถี่วิทยุ บทที่ 06 ย่านความถี่คลื่นแม่เหล็กไฟฟ้าสำหรับการสื่อสารไร้สาย
RFID Radio-Frequency Identification การระบุเอกลักษณ์ด้วยคลื่นความถี่วิทยุ บทที่ 01 ใช้แท็กคลื่นวิทยุติดสินค้าเพื่อเช็กสต็อกอัตโนมัติใน Smart Retail
RH Relative Humidity ความชื้นสัมพัทธ์ในอากาศ บทที่ 09 ร้อยละของปริมาณไอน้ำในอากาศเทียบกับปริมาณไอน้ำอิ่มตัวที่อุณหภูมินั้น
RTC Real-Time Clock นาฬิกาบอกเวลาจริง บทที่ 02 วงจรนับเวลา วินาที นาที ชั่วโมง วันที่ บนตัวบอร์ด KidBright
SBC Single-Board Computer คอมพิวเตอร์บอร์ดเดี่ยว บทที่ 01 คอมพิวเตอร์ที่รวมทุกวงจรไว้บนบอร์ดเดียว ติดตั้ง OS ตัวเต็มได้ เช่น Raspberry Pi
SSL / TLS Secure Sockets Layer / Transport Layer Security โพรโทคอลความปลอดภัยสำหรับการเข้ารหัสข้อมูลบนเครือข่าย บทที่ 10 ใช้รักษาความปลอดภัยเมื่อเชื่อมต่อไปยังพอร์ต 8883 ของ HiveMQ Cloud
SW Switch สวิตช์ไฟฟ้า บทที่ 08 อุปกรณ์ตัดต่อวงจรด้วยมือ เช่น ไมโครสวิตช์ปุ่มกด

Introduction to IoT (บทนำอินเทอร์เน็ตของสรรพสิ่ง)

ความหมายของ IoT, สถาปัตยกรรม 3 ระดับ, การประยุกต์ใช้งาน, บอร์ดไมโครคอนโทรลเลอร์ และการจำแนกอุปกรณ์

คำย่อ คำเต็มภาษาอังกฤษ ความหมายภาษาไทย การใช้งานในบทนี้
IoT Internet of Things อินเทอร์เน็ตของสรรพสิ่ง เครือข่ายของสิ่งของหรืออุปกรณ์ที่ฝังเซ็นเซอร์และซอฟต์แวร์ให้สามารถแลกเปลี่ยนข้อมูลกันผ่านอินเทอร์เน็ตได้อัตโนมัติ
M2M Machine-to-Machine การสื่อสารระหว่างเครื่องจักรกับเครื่องจักร การแลกเปลี่ยนข้อมูลโดยตรงระหว่างอุปกรณ์ปลายทางโดยไม่มีมนุษย์เข้ามาแทรกแซง
WSN Wireless Sensor Network เครือข่ายเซ็นเซอร์ไร้สาย กลุ่มเซ็นเซอร์กระจายตัวเก็บข้อมูลสภาพแวดล้อม (ความชื้น อุณหภูมิ แสง) และส่งผ่านคลื่นวิทยุ
CCTV Closed-Circuit Television กล้องโทรทัศน์วงจรปิด ระบบส่งสัญญาณภาพจากกล้องไปยังจุดรับชมเฉพาะจุดเพื่อการรักษาความปลอดภัยและจราจร
GPS Global Positioning System ระบบระบุพิกัดตำแหน่งบนโลกผ่านดาวเทียม ใช้ระบุละติจูดและลองจิจูดของอุปกรณ์ เช่น รถยนต์อัจฉริยะ โดรน หรือสมาร์ตโฟน
RFID Radio-Frequency Identification การระบุเอกลักษณ์ด้วยคลื่นความถี่วิทยุ ใช้แท็กคลื่นวิทยุติดสินค้าเพื่อเช็กสต็อกอัตโนมัติใน Smart Retail
NFC Near Field Communication การสื่อสารไร้สายระยะใกล้มาก ระยะ 4-10 ซม. ใช้ในการแตะจ่ายเงินหรือจับคู่อุปกรณ์อย่างรวดเร็ว
BLE Bluetooth Low Energy บลูทูธพลังงานต่ำ โปรโตคอลสื่อสารระยะสั้นกินไฟน้อยมาก เหมาะกับ Smart Wearable และเซ็นเซอร์พกพา
OS Operating System ระบบปฏิบัติการ ซอฟต์แวร์ระบบ เช่น Linux, Windows, RTOS ที่ใช้จัดการทรัพยากรของอุปกรณ์
MCU Microcontroller Unit หน่วยควบคุมขนาดเล็ก / ไมโครคอนโทรลเลอร์ ไอซีที่รวม CPU, RAM, ROM, I/O ไว้ในตัว เช่น ESP32, ESP8266, Arduino
SBC Single-Board Computer คอมพิวเตอร์บอร์ดเดี่ยว คอมพิวเตอร์ที่รวมทุกวงจรไว้บนบอร์ดเดียว ติดตั้ง OS ตัวเต็มได้ เช่น Raspberry Pi
V2X Vehicle-to-Everything การสื่อสารระหว่างยานพาหนะกับทุกสรรพสิ่ง รถยนต์คุยกับรถคันอื่น (V2V), คุยกับโครงสร้างพื้นฐานถนน (V2I), คุยกับคนเดินเท้า (V2P)

  • ทำไมแนวโน้ม IoT ถึงเติบโตสูงและได้รับความนิยมในอนาคต?:

  • ตอบโจทย์ความสะดวกสบาย ประหยัดพลังงาน และเพิ่มความปลอดภัยในชีวิตประจำวัน

  • องค์ประกอบ 3 ส่วนหลักของระบบ IoT (สถาปัตยกรรม 3 ชั้น):
  • 1. End Nodes (Edge Devices / ปลายทาง): อุปกรณ์เซ็นเซอร์ (รับค่าจากสิ่งแวดล้อม) และอุปกรณ์ขับเคลื่อน (Actuators เช่น มอเตอร์ วาล์ว รีเลย์ หลอดไฟ) ควบคุมโดยไมโครคอนโทรลเลอร์
  • 2. Connectivity (ระบบเชื่อมต่อ): ช่องทางการสื่อสาร ทั้งระยะใกล้ (Bluetooth, BLE, Zigbee, Wi-Fi) และระยะไกล (Cellular 4G/5G, NB-IoT, LoRaWAN) ทำหน้าที่ส่งต่อข้อมูล
  • 3. Central Servers / Cloud (เซิร์ฟเวอร์กลาง): ทำหน้าที่รวบรวมข้อมูล วิเคราะห์ ประมวลผล จัดเก็บลงฐานข้อมูล และแสดงผลหน้าแดชบอร์ด (Dashboard) ให้ผู้ใช้ดูหรือสั่งการย้อนกลับ
  • ความรู้และทักษะที่ต้องใช้ในการพัฒนา IoT:
  • ด้าน Hardware: วงจรอิเล็กทรอนิกส์พื้นฐาน การอ่านสัญลักษณ์ การใช้เบรดบอร์ด การบัดกรี การเลือกใช้ไมโครคอนโทรลเลอร์และเซ็นเซอร์ให้ตรงกับงาน
  • ด้าน Software: การเขียนโปรแกรมฝังตัว (Embedded C/C++, MicroPython, Block-based), โปรโตคอลการสื่อสาร (HTTP, MQTT, WebSocket), การพัฒนา Web Application และ API
💡 คำอธิบายเสริมทางเทคนิค: การออกแบบ IoT ที่ดีต้องคำนึงถึง 'ข้อจำกัดด้านพลังงาน' (Power Constraints) เนื่องจาก End Nodes หลายชนิดใช้แบตเตอรี่ จึงต้องออกแบบให้มีโหมด Deep Sleep และเลือกโปรโตคอลที่มีขนาด Header เล็กมาก เช่น MQTT หรือ CoAP แทนที่จะใช้ HTTP ซึ่งมีโอเวอร์เฮดสูง

สไลด์ 4: หลักการฟิสิกส์และการทำงานของเซ็นเซอร์ Ultrasonic (HC-SR04)

สไลด์ 4 🔍 คลิกขยาย
  • หลักการสะท้อนของคลื่นเสียงความถี่สูง (Ultrasonic Wave Echo Principle):
  • หูมนุษย์ได้ยินเสียงในช่วง 20 Hz - 20,000 Hz (20 kHz) แต่คลื่นอัลตราโซนิกจะมีความถี่สูงกว่า 20 kHz โดยเซ็นเซอร์ HC-SR04 ทำงานที่ความถี่มาตรฐาน 40,000 Hz (40 kHz)
  • บอร์ด KidBright ส่งพัลส์ลอจิก HIGH ไปยังขา Trig กว้างอย่างน้อย 10 ไมโครวินาที ($10\,\mu ext{s}$)
  • ตัวส่งสัญญาณ (Transmitter รูปตัว T) จะยิงคลื่นอัลตราโซนิกความถี่ 40 kHz ออกไปเป็นชุด 8 ลูก (Sonic Burst)
  • คลื่นเสียงเดินทางผ่านอากาศไปกระทบกับวัตถุกีดขวางข้างหน้า แล้วสะท้อนกลับมายังตัวรับสัญญาณ (Receiver รูปตัว R)
  • เมื่อตัวรับตรวจพบคลื่นสะท้อน ขา Echo จะสร้างสัญญาณพัลส์ HIGH ขึ้นมา โดยความกว้างของช่วงเวลา HIGH นี้ จะมีค่าเท่ากับ 'ระยะเวลาทั้งหมดที่คลื่นเสียงใช้เดินทางไปและกลับ'
  • สูตรคณิตศาสตร์ในการคำนวณหาระยะทาง:
  • $$\text{Distance} = \frac{\text{Speed of Sound} \times \text{Time}}{2}$$
  • อัตราเร็วของเสียงในอากาศที่อุณหภูมิห้อง ($pprox 25^\circ\text{C}$) เท่ากับประมาณ 343 เมตร/วินาที หรือ 0.0343 เซนติเมตรต่อไมโครวินาที
  • ต้องนำผลคูณมาหารด้วย 2 เนื่องจากคลื่นเดินทางไปและกลับ (ระยะทางสองเท่า):
  • $$\text{Distance (cm)} = \frac{\text{Time } (\mu\text{s}) \times 0.0343}{2} = \frac{\text{Time } (\mu\text{s})}{58.3}$$
💡 คำอธิบายเสริม: เซ็นเซอร์อัลตราโซนิกมีข้อดีเหนือเซ็นเซอร์แสงคือ 'ไม่ขึ้นกับสีหรือความโปร่งแสงของวัตถุ' (ตรวจจับกระจกใส วัตถุสีดำ หรือห้องมืดสนิทได้แม่นยำเท่ากัน) แต่มีจุดอ่อนหากผิววัตถุเป็นผ้านุ่มดูดกลืนเสียง หรือวัตถุเอียงทำมุมมากกว่า 45 องศาทำให้คลื่นสะท้อนเฉไปทางอื่น

คำย่อ คำเต็มภาษาอังกฤษ ความหมายภาษาไทย การใช้งานในบทนี้
R Resistor / Resistance ตัวต้านทาน / ค่าความต้านทานไฟฟ้า อุปกรณ์จำกัดปริมาณกระแสไฟฟ้า หน่วยวัดเป็น โอห์ม (Ohm: $\Omega$)
LED Light-Emitting Diode ไดโอดเปล่งแสง อุปกรณ์สารกึ่งตัวนำที่เปล่งแสงเมื่อได้รับแรงดันไบแอสตรง
DC / VDC Direct Current / Volts Direct Current ไฟฟ้ากระแสตรง / โวลต์กระแสตรง ไฟฟ้าที่มีทิศทางการไหลขั้วเดียวสม่ำเสมอ เช่น แบตเตอรี่ ถ่านไฟฉาย วงจรไมโครคอนโทรลเลอร์
AC / VAC Alternating Current / Volts Alternating Current ไฟฟ้ากระแสสลับ / โวลต์กระแสสลับ ไฟฟ้าที่มีทิศทางและขนาดเปลี่ยนแปลงเป็นรูปคลื่นไซน์ เช่น ไฟฟ้าตามบ้าน 220V 50Hz
C Capacitor / Capacitance ตัวเก็บประจุ / ค่าความจุไฟฟ้า อุปกรณ์กักเก็บและคายประจุไฟฟ้า หน่วยวัดเป็น ฟารัด (Farad: F)
F Farad ฟารัด หน่วยวัดความจุประจุไฟฟ้าตามระบบสากล SI
$\mu$F Microfarad ไมโครฟารัด ($10^{-6}$ ฟารัด) หน่วยความจุที่พบบ่อยที่สุดในวงจรอิเล็กทรอนิกส์
RF Radio Frequency ความถี่วิทยุ ย่านความถี่คลื่นแม่เหล็กไฟฟ้าสำหรับการสื่อสารไร้สาย
IC Integrated Circuit วงจรรวม / วงจรเบ็ดเสร็จ (ไอซี) ชิปซิลิคอนขนาดเล็กที่รวมชิ้นส่วนวงจรอิเล็กทรอนิกส์หลายล้านตัวไว้ภายใน
Ah Ampere-hour แอมแปร์-ชั่วโมง หน่วยวัดความจุพลังงานไฟฟ้าของแบตเตอรี่ (จ่ายกระแส 1 แอมแปร์ได้นานกี่ชั่วโมง)

  • ทนกระแสไฟฟ้าใช้งาน ($I_F$): ประมาณ 20 มิลลิแอมป์ (20 mA) หรือ 0.02 แอมแปร์ (A)
  • *ข้อควรระวัง*: หากต่อ LED เข้ากับแหล่งจ่ายไฟที่เกิน 3V โดยไม่มีตัวต้านทานดรอปกระแส กระแสไฟฟ้าจะพุ่งสูงจนหลอดไหม้เสียหายทันที
  • สูตรการคำนวณค่าตัวต้านทานสำหรับ LED (สไลด์ 20):
  • $$R = \frac{E}{I} = \frac{V_{\text{supply}} - V_{\text{LED}}}{I_{\text{LED}}}$$
  • เฉลยตัวอย่างการคำนวณในสไลด์ 20:
  • แหล่งจ่ายไฟ $V_{\text{supply}} = 12\,\text{VDC}$
  • แรงดันตกคร่อมที่ LED ต้องการ $V_{\text{LED}} = 3\,\text{VDC}$
  • แรงดันที่ต้องตกคร่อมตัวต้านทาน $E = 12\text{V} - 3\text{V} = 9\,\text{V}$
  • แปลงกระแสที่ต้องการ $20\,\text{mA} = 20 / 1000 = 0.02\,\text{A}$
  • แทนค่าในสูตร: $R = \frac{9\,\text{V}}{0.02\,\text{A}} = \mathbf{450\,\Omega}$ (ในทางปฏิบัติสามารถใช้ตัวต้านทานค่ามาตรฐานที่ใกล้เคียงคือ $470\,\Omega$)
💡 คำอธิบายเสริมกำลังสูญเสีย (Wattage): ตัวต้านทานตัวนี้จะมีความร้อนเกิดขึ้นเท่ากับ $P = I^2 R = (0.02)^2 \times 450 = 0.18\,\text{Watt}$ ดังนั้นจึงควรเลือกใช้ตัวต้านทานขนาดทนกำลัง $1/4\,\text{Watt}$ (0.25W) ขึ้นไป เพื่อไม่ให้ตัวต้านทานร้อนจนไหม้

  • 2. ตัวเก็บประจุชนิดเซรามิก (Ceramic Capacitor - สไลด์ 24): ทรงกลมแบนเหมือนเหรียญหรือสี่เหลี่ยม ไม่มีขั้ว (ต่อด้านใดก็ได้) ราคาถูก ทนแรงดันได้ 50-100V มีค่าความจุต่ำ (น้อยกว่า 1 $\mu\text{F}$ เช่น ระดับ pF, nF) เหมาะสำหรับกรองสัญญาณรบกวนความถี่สูง
  • 3. ตัวเก็บประจุชนิดไมลาร์ (Mylar Capacitor - สไลด์ 25): ใช้ฟิล์มโพลีเอสเตอร์เป็นฉนวนไดอิเล็กทริก ทรงสี่เหลี่ยมหรือหยดน้ำ ทนความชื้นและทนแรงดันไฟฟ้าสูงได้ถึง 350 โวลต์ มีค่าความจุมากกว่า 1 $\mu\text{F}$ เหมาะสำหรับวงจรกรองความถี่สูง วงจรวิทยุ (RF) และวงจรแรงดันสูง
💡 คำอธิบายเสริมรหัสตัวเลขบนตัวเก็บประจุเซรามิก: เช่น รหัส 104 หมายถึง เลข 10 ตามด้วยเลข 0 จำนวน 4 ตัว หน่วยเป็นพิโกฟารัด (pF) คือ $100,000\,\text{pF} = 100\,\text{nF} = 0.1\,\mu\text{F}$ ซึ่งเป็นค่ามาตรฐานที่นิยมต่อขนานคร่อมขา VCC และ GND ของไอซีเพื่อดักจับสัญญาณรบกวน (Decoupling Capacitor)

  • เซลล์ไฟฟ้า (Electric Cell): แหล่งกำเนิดไฟฟ้าที่แปลงพลังงานเคมีเป็นพลังงานไฟฟ้า มีขั้วบวก (+) และขั้วลบ (-)
  • 1. การต่อเซลล์ไฟฟ้าแบบอนุกรม (Series Connection - สไลด์ 38-44):
  • วิธีต่อ: นำขั้วบวกของก้อนแรก ไปต่อเข้ากับขั้วลบของก้อนถัดไป เรียงต่อกันเป็นแถว
  • แรงดันไฟฟ้ารวม ($V_{\text{รวม}}$): นำแรงดันของแต่ละก้อนมาบวกกัน ($V_{\text{รวม}} = V_1 + V_2 + V_3 + \dots$)
  • ความจุและกระแสรวม ($Ah_{\text{รวม}}$): มีค่าเท่าเดิม ไม่เพิ่มขึ้น ($Ah_{\text{รวม}} = Ah$)
  • ตัวอย่าง: ถ่าน 1.5V 1000mAh จำนวน 4 ก้อนต่ออนุกรม จะได้ $1.5\text{V} \times 4 = \mathbf{6.0\,\text{V}}$ ที่ความจุเท่าเดิมคือ $\mathbf{1000\,\text{mAh}}$
  • 2. การต่อเซลล์ไฟฟ้าแบบขนาน (Parallel Connection - สไลด์ 45-49):
  • วิธีต่อ: นำขั้วบวกทุกก้อนมาต่อรวมเข้าด้วยกัน และนำขั้วลบทุกก้อนมาต่อรวมเข้าด้วยกัน
  • แรงดันไฟฟ้ารวม ($V_{\text{รวม}}$): มีค่าเท่าเดิม เท่ากับแรงดันของหนึ่งก้อน ($V_{\text{รวม}} = V$)
  • ความจุรวม ($Ah_{\text{รวม}}$): นำความจุของแต่ละก้อนมาบวกกัน ทำให้ใช้งานได้ยาวนานขึ้น ($Ah_{\text{รวม}} = Ah_1 + Ah_2 + \dots$)
  • ตัวอย่าง: ถ่าน 1.5V 1000mAh จำนวน 4 ก้อนต่อขนาน จะได้แรงดันคงที่ $\mathbf{1.5\,\text{V}}$ แต่ความจุเพิ่มขึ้นเป็น $1000 \times 4 = \mathbf{4000\,\text{mAh}}$

สไลด์ 50 🔍 คลิกขยาย
  • ข้อที่ 1: จงอธิบายความสำคัญของตัวต้านทาน
  • *คำตอบ*: ตัวต้านทานมีความสำคัญอย่างยิ่งในวงจรอิเล็กทรอนิกส์ ได้แก่:
  • 1. จำกัดกระแสไฟฟ้า (Current Limiting): ควบคุมไม่ให้กระแสไหลผ่านอุปกรณ์เกินพิกัด เช่น ดรอปกระแสให้หลอดไฟ LED หรือขาอินพุตของไมโครคอนโทรลเลอร์ เพื่อป้องกันอุปกรณ์ไหม้เสียหาย
  • 2. แบ่งแรงดันไฟฟ้า (Voltage Divider): ใช้ลดทอนระดับแรงดันไฟฟ้าให้เหมาะสมกับเซ็นเซอร์ หรือแปลงสัญญาณแอนะล็อกให้อยู่ในช่วงที่ ADC อ่านค่าได้ (เช่น 0-3.3V)
  • 3. กำหนดระดับลอจิก (Pull-up / Pull-down): ป้องกันสภาวะขาลอย (Floating state) ในวงจรสวิตช์
  • ข้อที่ 2: จงอธิบายความแตกต่างของไฟ DC และ AC
  • *คำตอบ*:
  • - ไฟ DC (Direct Current - ไฟฟ้ากระแสตรง): กระแสไฟฟ้ามีทิศทางการไหลขั้วเดียวสม่ำเสมอจากขั้วบวกไปขั้วลบ ขั้วไฟฟ้าคงที่ไม่สลับที่ แรงดันเรียบสม่ำเสมอ เกิดจากแบตเตอรี่ โซลาร์เซลล์ หรือหม้อแปลงแปลงไฟ เหมาะสำหรับอุปกรณ์อิเล็กทรอนิกส์ คอมพิวเตอร์ และบอร์ด IoT
  • - ไฟ AC (Alternating Current - ไฟฟ้ากระแสสลับ): กระแสไฟฟ้ามีทิศทางการไหลสลับไปมาตามรอบเวลา เป็นรูปคลื่นไซน์ (Sine Wave) มีการสลับขั้วบวกและลบตลอดเวลา เช่น ไฟฟ้าตามบ้านในไทยมีแรงดัน 220V ความถี่ 50 Hz (สลับขั้ว 50 รอบต่อวินาที) ข้อดีคือสามารถใช้หม้อแปลงเพิ่ม-ลดแรงดันได้ง่าย ทำให้ส่งกำลังไฟฟ้าแรงดันสูงระยะไกลผ่านเสาไฟฟ้าโดยมีพลังงานสูญเสียต่ำมาก
  • ข้อที่ 3: เมื่อนักศึกษาต้องเปลี่ยนแบตเตอรี่รถไฟฟ้าให้คุณยายที่ใช้ไฟ 48V ควรใช้แบตเตอรี่ขนาด 12V 8Ah กี่ก้อน และควรต่อแบตเตอรี่อย่างไร จงอธิบาย
  • *คำตอบอย่างละเอียด*:
  • - 1. จำนวนก้อนที่ต้องใช้: นำแรงดันรวมที่ระบบต้องการ (48V) หารด้วยแรงดันของแบตเตอรี่แต่ละก้อน (12V)
  • $$\text{จำนวนแบตเตอรี่} = \frac{48\,\text{V}}{12\,\text{V}} = \mathbf{4\,\text{ก้อน}}$$
  • - 2. วิธีการต่อวงจร: ต้องต่อแบตเตอรี่ทั้ง 4 ก้อนแบบ 'อนุกรม' (Series Connection)
  • - 3. อธิบายการต่อสาย:
  • - นำขั้วบวก (+) ของแบตเตอรี่ก้อนที่ 1 ต่อเข้าขั้วลบ (-) ของก้อนที่ 2
  • - นำขั้วบวก (+) ของก้อนที่ 2 ต่อเข้าขั้วลบ (-) ของก้อนที่ 3
  • - นำขั้วบวก (+) ของก้อนที่ 3 ต่อเข้าขั้วลบ (-) ของก้อนที่ 4
  • - จะเหลือขั้วลบ (-) ของก้อนที่ 1 และขั้วบวก (+) ของก้อนที่ 4 นำไปต่อใช้งานกับมอเตอร์รถไฟฟ้าของคุณยาย
  • - 4. ผลลัพธ์ทางไฟฟ้า: จะได้แรงดันไฟฟ้ารวม $12\text{V} + 12\text{V} + 12\text{V} + 12\text{V} = \mathbf{48\,\text{V}}$ พอดีกับมอเตอร์ โดยมีความจุคงที่อยู่ที่ $\mathbf{8\,\text{Ah}}$

คำย่อ คำเต็มภาษาอังกฤษ ความหมายภาษาไทย การใช้งานในบทนี้
MCU Microcontroller Unit หน่วยควบคุมขนาดเล็ก / ไมโครคอนโทรลเลอร์ ชิปคอมพิวเตอร์ขนาดเล็กที่รวมส่วนประมวลผล หน่วยความจำ และพอร์ต I/O
NodeMCU Node Microcontroller Unit บอร์ดพัฒนาอุปกรณ์ IoT ตระกูล ESP8266 แบบ Open-source บอร์ดพัฒนาที่รวบรวมชิป ESP8266, ภาคจ่ายไฟ 3.3V, และชิปแปลง USB-to-UART ไว้บนบอร์ดเดียว
ESP8266 Espressif Systems SoC model 8266 ชิปประมวลผล 32-bit พร้อม Wi-Fi ในตัวของบริษัท Espressif หัวใจประมวลผลหลักของ NodeMCU ทำงานที่ความถี่ 80/160 MHz
IDE Integrated Development Environment สภาพแวดล้อมสำหรับการพัฒนาแบบเบ็ดเสร็จ (Arduino IDE) ซอฟต์แวร์สำหรับเขียน คอมไพล์ และเบิร์นโปรแกรมลงชิป
USB Universal Serial Bus พอร์ตเชื่อมต่อและสื่อสารข้อมูลมาตรฐาน ใช้จ่ายไฟ 5V และถ่ายโอนข้อมูลโค้ดผ่านสายเคเบิล Micro-USB
UART Universal Asynchronous Receiver-Transmitter วงจรสื่อสารอนุกรมแบบอะซิงโครนัส โปรโตคอลสื่อสารแบบ Serial ใช้คุยระหว่างคอมพิวเตอร์กับบอร์ดผ่านขา TX/RX
COM Communication Port พอร์ตสื่อสารอนุกรมเสมือนบนระบบปฏิบัติการ เช่น COM3, COM4 ที่ Windows กำหนดให้กับบอร์ดที่เสียบ USB
JSON JavaScript Object Notation รูปแบบข้อมูลมาตรฐานที่ใช้ระบุลิงก์ Index ติดตั้งบอร์ด ไฟล์ package_esp8266com_index.json ที่ใส่ใน Preferences
GPIO General-Purpose Input/Output ขาอินพุต/เอาต์พุตอเนกประสงค์ ขาพอร์ตดิจิทัลบนบอร์ด เช่น D0-D8 (GPIO16, GPIO5, GPIO4 ฯลฯ)
LED Light-Emitting Diode ไดโอดเปล่งแสง หลอด LED สีน้ำเงินบนบอร์ด NodeMCU (ต่อกับขา GPIO2 / D4)

  • pinMode(LED_BUILTIN, OUTPUT);: ฟังก์ชันกำหนดโหมดของขา โดย LED_BUILTIN คือหลอดไฟ LED สีน้ำเงินบนบอร์ด NodeMCU ซึ่งต่ออยู่กับขา GPIO2 (ขา D4) และกำหนดโหมดเป็น OUTPUT เพื่อให้สามารถจ่ายกระแสไฟหรือดึงกระแสไฟได้
  • ทำไมสั่ง LOW ถึงติด สั่ง HIGH ถึงดับ? (Active-LOW Architecture):
  • - วงจร LED บนบอร์ด NodeMCU ต่อแบบ Active-LOW หมายความว่า ขาแอโนด (+) ของ LED ต่อค้างไว้กับไฟบวก 3.3V ผ่านตัวต้านทาน ส่วนขาแคโทด (-) ต่อเข้ากับขา GPIO2 ของชิป
  • - เมื่อสั่ง digitalWrite(LED_BUILTIN, LOW): ขา GPIO2 มีแรงดัน 0V (กราวด์) ทำให้เกิดความต่างศักย์ กระแสไฟฟ้าจึงไหลผ่านหลอด LED $\rightarrow$ หลอดไฟติดสว่าง
  • - เมื่อสั่ง digitalWrite(LED_BUILTIN, HIGH): ขา GPIO2 มีแรงดัน 3.3V เท่ากับไฟเลี้ยง จึงไม่มีความต่างศักย์ กระแสไม่ไหล $\rightarrow$ หลอดไฟดับ

I/O Input / Output สัญญาณขาเข้าและขาออก พอร์ตติดต่อสื่อสารระหว่างไมโครคอนโทรลเลอร์กับอุปกรณ์ภายนอก
GPIO General-Purpose Input/Output ขาอินพุต/เอาต์พุตอเนกประสงค์ ขาพินบนชิป ESP32 ที่สามารถสั่งการเป็นได้ทั้งดิจิทัล แอนะล็อก หรือสื่อสารข้อมูล
ESP32 Espressif Systems 32-bit Dual-core Microcontroller ไมโครคอนโทรลเลอร์ทรงพลัง 2 คอร์ พร้อม Wi-Fi และ Bluetooth ในตัว บอร์ดประมวลผลหลักที่ใช้ในการทดลองบทนี้ (NodeMCU ESP32 30/38 pins)
PWM Pulse Width Modulation การมอดูเลตความกว้างสัญญาณพัลส์ เทคนิคการเปิด-ปิดสัญญาณดิจิทัลอย่างรวดเร็วเพื่อจำลองระดับแรงดันแอนะล็อก เช่น หรี่ไฟ LED
ADC / A/D Analog-to-Digital Converter ตัวแปลงสัญญาณแอนะล็อกเป็นดิจิทัล วงจรแปลงระดับแรงดันไฟฟ้าต่อเนื่อง (0-3.3V) ให้เป็นค่าตัวเลขดิจิทัล 10-bit (0-1023) หรือ 12-bit (0-4095)
DAC / D/A Digital-to-Analog Converter ตัวแปลงสัญญาณดิจิทัลเป็นแอนะล็อก วงจรสร้างแรงดันไฟฟ้าแอนะล็อกของจริงจากค่าตัวเลขดิจิทัล
VCC Voltage Common Collector ไฟเลี้ยงขั้วบวกของระบบ (3.3V หรือ 5V) ระดับแรงดันไฟฟ้าสูงสุดของระบบลอจิก
GND Ground ขั้วกราวด์ / ระดับแรงดันศูนย์โวลต์ (0V) จุดอ้างอิงแรงดันไฟฟ้าร่วมของวงจร
Vin Voltage Input ช่องรับแรงดันไฟเลี้ยงจากภายนอก รับไฟบวก 5V - 12V เข้าสู่วงจรควบคุมแรงดัน LDO บนบอร์ด
SW Switch สวิตช์ไฟฟ้า อุปกรณ์ตัดต่อวงจรด้วยมือ เช่น ไมโครสวิตช์ปุ่มกด
LED Light-Emitting Diode ไดโอดเปล่งแสง โหลดเอาต์พุตสำหรับแสดงสถานะการทำงาน

  • ปัญหาขาลอย (Floating State) คืออะไร? ทำไมต้องมีตัวต้านทาน Pull-up / Pull-down?:
  • หากนำสวิตช์มาต่อตรง ๆ ระหว่างขา GPIO กับแหล่งจ่ายไฟ เมื่อเรายังไม่กดสวิตช์ ขา GPIO จะลอยอยู่กลางอากาศ (High Impedance)
  • ขาที่ลอยอยู่จะทำหน้าที่เหมือนเสาอากาศ รับคลื่นแม่เหล็กไฟฟ้า คลื่นวิทยุ และประจุไฟฟ้าสถิตรอบข้าง ทำให้ค่าที่อ่านได้แกว่งไปมาระหว่าง 0 กับ 1 อย่างมั่วซั่ว ไม่สามารถควบคุมได้
  • จึงจำเป็นต้องมี ตัวต้านทานค่าสูง (เช่น 10 k$\Omega$) มาคอย 'ดึง' ระดับแรงดันของขาไว้ให้คงที่ในสภาวะปกติ
  • 1. วงจรดึงลง (Pull-Down Resistor - สไลด์ 29):
  • ต่อตัวต้านทาน 10 k$\Omega$ จากขา Input ลง GND และต่อสวิตช์ไปที่ VCC (3.3V)
  • สภาวะปกติ (ไม่กด): ตัวต้านทานดึงขาลงกราวด์ $\rightarrow$ อ่านค่าได้ LOW (0)
  • เมื่อกดสวิตช์: ไฟบวกจาก VCC ไหลเข้าขา Input $\rightarrow$ อ่านค่าได้ HIGH (1)
  • 2. วงจรดึงขึ้น (Pull-Up Resistor - สไลด์ 29):
  • ต่อตัวต้านทาน 10 k$\Omega$ จากขา Input ขึ้น VCC (3.3V) และต่อสวิตช์ลง GND
  • สภาวะปกติ (ไม่กด): ตัวต้านทานดึงขาขึ้นไฟบวก $\rightarrow$ อ่านค่าได้ HIGH (1)
  • เมื่อกดสวิตช์: ขาถูกช็อตลงกราวด์ $\rightarrow$ อ่านค่าได้ LOW (0)
  • 3. โหมด Internal Pull-Up (ดึงขึ้นภายในบอร์ด - สไลด์ 32-34):
  • ในชิป ESP32/Arduino มีตัวต้านทาน Pull-up ขนาด 45 k$\Omega$ ฝังอยู่ข้างในชิปแล้วทุกขา
  • เปิดใช้งานง่าย ๆ ด้วยคำสั่ง: pinMode(SW, INPUT_PULLUP);
  • วิธีต่อวงจร (ง่ายที่สุด): ต่อสวิตช์ขาหนึ่งเข้า GPIO (เช่น ขา 23) และขาอีกด้านต่อลง GND ตรง ๆ ได้เลย ไม่ต้องต่อตัวต้านทานภายนอก!
  • สภาวะการทำงาน: สวิตช์ยังไม่กด $\rightarrow$ อ่านได้ 1, เมื่อกดสวิตช์ $\rightarrow$ อ่านได้ 0
💡 ข้อสังเกตเชิงปฏิบัติ: ในอุตสาหกรรมนิยมใช้งานแบบ Pull-Up (Active-LOW) มากกว่า Pull-Down เพราะปลอดภัยกว่า หากสายไฟสวิตช์ขาดหรือหลุดจะเทียบเท่ากับสภาวะไม่กด (ปลอดภัยต่อระบบ) และไม่ต้องเดินสายไฟบวก VCC ไปยังปุ่มกดภายนอก ลดความเสี่ยงไฟช็อตลงตัวถังเครื่อง

COM Common Terminal ขั้วต่อแกนกลางร่วมของสวิตช์รีเลย์ จุดต่อสายไฟร่วมที่ต่อเชื่อมกับหน้าสัมผัสโยกภายใน
NO Normally Open หน้าสัมผัสปกติเปิด สภาวะปกติวงจรเปิด (ไฟไม่ผ่าน) เมื่อรีเลย์ทำงานหน้าสัมผัสจะดูดติดกัน ไฟจึงจะไหลผ่าน
NC Normally Closed หน้าสัมผัสปกติปิด สภาวะปกติวงจรปิด (ไฟไหลผ่านตลอด) เมื่อรีเลย์ทำงานหน้าสัมผัสจะถูกดึงแยกออก วงจรจะถูกตัดขาด
DHT11 Digital Humidity and Temperature Sensor Model 11 เซ็นเซอร์วัดอุณหภูมิและความชื้นสัมพัทธ์แบบดิจิทัลรุ่น 11 เซ็นเซอร์ยอดนิยมส่งข้อมูลดิจิทัลทางสายเดี่ยว (Single-wire serial)
RH Relative Humidity ความชื้นสัมพัทธ์ในอากาศ ร้อยละของปริมาณไอน้ำในอากาศเทียบกับปริมาณไอน้ำอิ่มตัวที่อุณหภูมินั้น
GPIO General-Purpose Input/Output ขาอินพุต/เอาต์พุตอเนกประสงค์ เช่น ขา GPIO4 หรือ GPIO22 ที่ใช้เชื่อมต่อขา DATA ของ DHT11

สไลด์ 1 - 3: สัญญาณแอนะล็อกและวงจรแปลงสัญญาณ A/D (Analog to Digital)

สไลด์ 1 🔍 คลิกขยาย
สไลด์ 2 🔍 คลิกขยาย
สไลด์ 3 🔍 คลิกขยาย
  • ความแตกต่างระหว่างสัญญาณแอนะล็อกกับดิจิทัล (สไลด์ 2):
  • สัญญาณแอนะล็อก (Analog Signal): เป็นสัญญาณไฟฟ้าที่มีความต่อเนื่อง ขนาดของสัญญาณเปลี่ยนแปลงตามเวลาและค่าทางกายภาพในธรรมชาติ (แสงแดด อุณหภูมิ เสียง แรงดัน)
  • สัญญาณดิจิทัล (Digital Signal): มีสถานะไม่ต่อเนื่อง มีเพียง 2 ระดับตายตัวคือ 0 (LOW) หรือ 1 (HIGH)
  • การทำงานของวงจร A/D 10 บิต บนไมโครคอนโทรลเลอร์ (สไลด์ 2-3):
  • ทำหน้าที่สุ่มวัดระดับแรงดันไฟฟ้า (0V ถึง 3.3V หรือ 5V) แล้วแปลงเป็นตัวเลขจำนวนเต็มดิจิทัลขนาด 10 บิต
  • จำนวนระดับความละเอียด: $2^{10} = 1024$ ระดับ มีค่าเป็นจำนวนเต็มตั้งแต่ 0 ถึง 1023
  • ไวยากรณ์คำสั่ง: value = analogRead(ขาพิน); โดยต้องประกาศตัวแปร value เป็นชนิดจำนวนเต็ม (int)
💡 สูตรการแปลงค่า ADC กลับเป็นแรงดันไฟฟ้าจริง: $V_{\text{in}} = \frac{\text{ADC Value}}{1023} \times V_{\text{ref}}$ เช่น ถ้าอ่านได้ค่า 511 บนระบบ 3.3V แรงดันที่ขาจะเท่ากับ $\frac{511}{1023} \times 3.3\text{V} \approx 1.65\,\text{V}$

  • ทำจากสารกึ่งตัวนำ แคดเมียมซัลไฟด์ (CdS)
  • เมื่ออยู่ในที่มืด: อิเล็กตรอนยึดแน่นในโครงสร้าง ความต้านทานจะสูงมาก (ระดับหลายเมกะโอห์ม $M\Omega$)
  • เมื่อได้รับแสงสว่าง: โฟตอนของแสงจะชนให้อิเล็กตรอนหลุดเป็นอิสระ ความต้านทานจะลดลงอย่างรวดเร็ว (เหลือเพียงไม่กี่ร้อยโอห์ม $\Omega$)
  • การต่อวงจรทดลองกับบอร์ด (สไลด์ 6):
  • ตัว LDR เพียงตัวเดียวไม่สามารถสร้างแรงดันได้ จึงต้องต่อร่วมกับตัวต้านทานคงที่ (เช่น $10\,\text{k}\Omega$) ในรูปแบบ วงจรแบ่งแรงดัน (Voltage Divider)
  • ขาเชื่อมต่อ: 3V3 (ไฟเลี้ยง 3.3V), GND (กราวด์), และดึงจุดกึ่งกลางระหว่าง LDR กับตัวต้านทานเข้าขา A0 ของบอร์ด

💡 การประยุกต์ใช้งาน: นำไปทำระบบเปิด-ปิดไฟหน้าบ้านอัตโนมัติ โดยเขียนเงื่อนไข if (analogRead(A0) < 300) { เปิดไฟถนน; }

สไลด์ 7 - 9: เซ็นเซอร์วัดความชื้นในดิน (Soil Moisture Sensor)

สไลด์ 8 🔍 คลิกขยาย
สไลด์ 9 🔍 คลิกขยาย
  • ส่วนประกอบของชุดเซ็นเซอร์วัดความชื้นในดิน (สไลด์ 7):
  • 1. แผ่นโพรบวัด (Probe YL-69): แผ่นลายวงจรทองแดง 2 ขาชุบสารป้องกันการกัดกร่อน สำหรับปักลงดินเพื่อตรวจจับความนำไฟฟ้า
  • 2. โมดูลเปรียบเทียบแรงดัน (LM393 Comparator Module): บอร์ดวงจรรวมขนาดเล็กที่มีโพเทนชิโอมิเตอร์สีน้ำเงินสำหรับหมุนตั้งค่าความไว (Sensitivity)
  • ขาเชื่อมต่อทั้ง 4 ขาของโมดูล (สไลด์ 7):
  • VCC: ต่อไฟเลี้ยง 3.3V ถึง 5V
  • GND: ต่อกราวด์ 0V
  • AO (Analog Output): เอาต์พุตแอนะล็อก ส่งระดับแรงดันไฟฟ้ารายงานค่าความชื้นแบบต่อเนื่อง (ดินเปียกมากนำไฟฟ้าดี $\rightarrow$ แรงดันต่ำ ค่า ADC ต่ำ; ดินแห้งนำไฟฟ้าแย่ $\rightarrow$ แรงดันสูง ค่า ADC สูง)
  • DO (Digital Output): เอาต์พุตดิจิทัล ส่งค่า 0 หรือ 1 ตัดตอนตามระดับความชื้นที่หมุนตั้งไว้ เหมาะสำหรับต่อตรงเข้าขาตัดต่อรีเลย์
💡 ข้อแนะนำการดูแลรักษาโพรบ: การจ่ายไฟเลี้ยงแช่ไว้ตลอดเวลาจะทำให้เกิดปฏิกิริยาอิเล็กโทรไลซิส (Electrolysis) ส่งผลให้ทองแดงที่ขาโพรบผุกร่อนเร็ว วิธีแก้ในระบบจริงคือ ให้ต่อขา VCC ของเซ็นเซอร์เข้ากับขา Digital Output ของบอร์ด และสั่งจ่ายไฟเฉพาะตอนที่จะอ่านค่า จากนั้นตัดไฟทันที

  • รีเลย์ (Relay) คืออะไรและทำหน้าที่อะไร? (สไลด์ 10-11): สวิตช์ควบคุมด้วยแม่เหล็กไฟฟ้า ทำหน้าที่เป็น 'ฉนวนแยกทางไฟฟ้า' (Galvanic Isolation) ระหว่างวงจรควบคุมแรงดันต่ำกระแสต่ำ (เช่น ESP32 3.3V) กับวงจรโหลดกำลังสูง (เช่น ปั๊มน้ำ 5V/12V หรือไฟบ้าน 220VAC) ป้องกันไม่ให้สัญญาณรบกวนหรือไฟกระชากย้อนกลับมาทำลายบอร์ดไมโครคอนโทรลเลอร์

  • VCC: ต่อไฟเลี้ยง 5V ของบอร์ด
  • GND: ต่อกราวด์ GND ของบอร์ด
  • IN (Input): รับสัญญาณลอจิกดิจิทัล (HIGH หรือ LOW) จากขาไมโครคอนโทรลเลอร์ (เช่น D7 หรือ GPIO22)

  • 2. NO (Normally Open - ปกติเปิด): สภาวะปกติวงจรเปิด (ไฟไม่ผ่าน) แต่เมื่อรีเลย์ทำงาน ขดลวดจะดูดหน้าสัมผัสมาแตะกับ COM ทำให้วงจรปิด ไฟฟ้าจึงไหลผ่านได้
  • 3. NC (Normally Closed - ปกติปิด): สภาวะปกติวงจรปิด (ไฟฟ้าไหลผ่านตลอดเวลา) แต่เมื่อรีเลย์ทำงาน หน้าสัมผัสจะถูกดึงแยกออกจาก COM ทำให้วงจรถูกตัดขาด ไฟฟ้าหยุดไหล
  • ตารางสรุปสถานะการทำงานของรีเลย์กับปั๊มน้ำ 5V (สไลด์ 13):
  • หน้าสัมผัส NO: ตอนรีเลย์ยังไม่ทำงาน $\rightarrow$ *วงจรไม่ต่อ ไฟไม่ผ่าน ปั๊มหยุดทำงาน*; ตอนรีเลย์ทำงาน $\rightarrow$ *วงจรปิด ไฟผ่าน ปั๊มน้ำทำงาน*
  • หน้าสัมผัส NC: ตอนรีเลย์ยังไม่ทำงาน $\rightarrow$ *วงจรปิด ไฟผ่าน ปั๊มน้ำทำงาน*; ตอนรีเลย์ทำงาน $\rightarrow$ *วงจรตัด ไฟไม่ผ่าน ปั๊มหยุดทำงาน*
💡 ทำไมงานรดน้ำต้นไม้ต้องต่อที่ขา NO?: เพราะในกรณีที่ระบบไฟฟ้าดับ บอร์ดค้าง หรือเกิดไฟตก รีเลย์จะหยุดทำงานและหน้าสัมผัส NO จะเปิดออก (ตัดไฟปั๊มน้ำทันที) ป้องกันไม่ให้น้ำล้นแปลงเกษตรจนเกิดความเสียหาย (Fail-safe Mechanism)

TCP/IP Transmission Control Protocol / Internet Protocol ชุดโปรโตคอลมาตรฐานสำหรับการสื่อสารบนเครือข่ายอินเทอร์เน็ต โปรโตคอลเลเยอร์เครือข่ายที่รับประกันความถูกต้องของการส่งแพ็กเก็ตข้อมูลที่ MQTT ทำงานอยู่ด้านบน
QoS Quality of Service ระดับการรับประกันคุณภาพในการส่งมอบข้อความ กลไกใน MQTT ที่กำหนดความน่าเชื่อถือของการส่งข้อมูล มี 3 ระดับ (QoS 0, QoS 1, QoS 2)
JSON JavaScript Object Notation รูปแบบการจัดเก็บและแลกเปลี่ยนข้อมูลข้อความที่เป็นมาตรฐานสากล โครงสร้างข้อมูลข้อความที่อ่านง่าย (Key-Value) นิยมใช้เป็น Payload ในระบบ IoT
ESP32 Espressif Systems 32-bit Dual-core Wi-Fi SoC ไมโครคอนโทรลเลอร์ประมวลผลหลักที่ทำหน้าที่เป็น MQTT Publisher บอร์ดไมโครคอนโทรลเลอร์ที่อ่านค่าเซ็นเซอร์และส่งขึ้น HiveMQ
DHT11 Digital Humidity and Temperature Sensor Model 11 เซ็นเซอร์วัดอุณหภูมิและความชื้นแบบดิจิทัล อุปกรณ์ตรวจวัดสภาพแวดล้อมที่ส่งค่าใน Lab 13
SSL / TLS Secure Sockets Layer / Transport Layer Security โพรโทคอลความปลอดภัยสำหรับการเข้ารหัสข้อมูลบนเครือข่าย ใช้รักษาความปลอดภัยเมื่อเชื่อมต่อไปยังพอร์ต 8883 ของ HiveMQ Cloud
GUI Graphical User Interface ส่วนต่อประสานกราฟิกกับผู้ใช้ เช่น หน้าจอโปรแกรม MQTT Explorer ที่แสดง Topic Tree เป็นรูปภาพต้นไม้
API Application Programming Interface ส่วนต่อประสานโปรแกรมประยุกต์ ช่องทางให้โปรแกรมภายนอกหรือหน้าเว็บดึงข้อมูลจาก Broker ไปแสดงผล

สไลด์ 2 🔍 คลิกขยาย
สไลด์ 3 🔍 คลิกขยาย
สไลด์ 4 🔍 คลิกขยาย
  • MQTT คืออะไร (สไลด์ 2): ย่อมาจาก Message Queuing Telemetry Transport เป็นโปรโตคอลการสื่อสารระดับแอปพลิเคชันที่ทำงานบนโพรโทคอลเครือข่าย TCP/IP ออกแบบมาตามสถาปัตยกรรมแบบ Publish / Subscribe (ผู้เผยแพร่ / ผู้รับข้อมูล)
  • จุดเด่นที่ทำให้ MQTT เป็นหัวใจของ IoT:
  • น้ำหนักเบามาก (Lightweight): ตัวหัวเรื่องของข้อความ (Packet Header) มีขนาดเริ่มต้นเพียง 2 ไบต์ (2 Bytes) เท่านั้น ต่างจาก HTTP ที่มีขนาด Header หลายร้อยไบต์
  • ประหยัดแบนด์วิดท์ (Low Bandwidth): เหมาะอย่างยิ่งสำหรับเครือข่ายที่มีความเร็วต่ำ เช่น ซิมการ์ด 2G/3G/4G หรือสัญญาณมือถือในพื้นที่ชนบท
  • กินพลังงานต่ำ (Low Power Consumption): เหมาะสำหรับอุปกรณ์ End Nodes ที่ต้องเปิดทำงานด้วยพลังงานจากแบตเตอรี่หรือโซลาร์เซลล์
  • 3 บทบาทหลักในระบบ MQTT (สไลด์ 3):
  • 1. Broker (แม่ข่ายตัวกลาง): ทำหน้าที่เป็นศูนย์กลางคอยรับข้อความทั้งหมดจากผู้ส่ง กรองหัวข้อ (Topic Filtering) และส่งต่อข้อความไปยังผู้รับที่ลงทะเบียนไว้
  • 2. Publisher (ผู้ส่งข้อมูล): อุปกรณ์หรือโปรแกรมที่สร้างข้อมูลและส่ง (Publish) ไปยังหัวข้อ (Topic) ที่ระบุบน Broker เช่น บอร์ด ESP32 อ่านค่าอุณหภูมิแล้วส่งขึ้นไป
  • 3. Subscriber (ผู้รับข้อมูล): อุปกรณ์หรือแอปพลิเคชันที่ลงทะเบียนขอรับข้อมูล (Subscribe) ในหัวข้อที่สนใจ เช่น หน้าเว็บ Dashboard หรือแอปพลิเคชันบนมือถือ
  • *ข้อได้เปรียบสูงสุด*: Publisher และ Subscriber ไม่จำเป็นต้องรู้จักกัน ไม่ต้องมี IP Address ของกันและกัน และไม่ต้องเปิดออนไลน์พร้อมกัน (Decoupled in Space and Time)
💡 การเปรียบเทียบกับ HTTP (Client-Server): ในระบบเว็บแบบเดิม (HTTP Request-Response) หากต้องการทราบค่าเซ็นเซอร์ หน้าเว็บจะต้องคอยส่งคำร้องขอ (Polling) ไปถามบอร์ดตลอดเวลา ซึ่งสิ้นเปลืองพลังงานและแบนด์วิดท์มาก แต่ใน MQTT บอร์ดจะส่งข้อมูลขึ้นมาเฉพาะตอนที่ค่าเปลี่ยนแปลง และ Broker จะเป็นฝ่าย 'ผลัก' (Push) ข้อมูลไปยังผู้รับทันทีในเสี้ยววินาที

สไลด์ 8: จุดเด่นของ MQTT และระดับคุณภาพการส่งมอบ (QoS Levels)

สไลด์ 8 🔍 คลิกขยาย
  • จุดเด่นที่ระบุในสไลด์ 8:
  • เบา (Lightweight): ตัว Header มีขนาดเล็กมากเริ่มต้นเพียง 2 ไบต์
  • ประหยัดพลังงาน: เหมาะสำหรับเซ็นเซอร์และอุปกรณ์ IoT ที่ใช้ไฟจากแบตเตอรี่
  • ทำงานบนเครือข่าย TCP/IP: รองรับทั้ง Wi-Fi, สาย LAN Ethernet, และเครือข่ายเซลลูลาร์
  • ระดับการรับประกันคุณภาพข้อความ (Quality of Service: QoS 3 ระดับ):
  • QoS 0 (At most once - ส่งอย่างมากหนึ่งครั้ง / ส่งแล้วลืม):
  • - ส่งข้อความออกไปเพียงครั้งเดียวโดยไม่มีการยืนยันการตอบรับกลับมา (No Acknowledgment)
  • - *ข้อดี*: เร็วที่สุด ใช้แบนด์วิดท์และพลังงานน้อยที่สุด
  • - *ข้อเสีย*: ข้อความอาจสูญหายได้หากสัญญาณเน็ตหลุด
  • - *ความเหมาะสม*: ใช้กับข้อมูลเซ็นเซอร์ทั่วไปที่ส่งถี่ ๆ ต่อเนื่อง (เช่น ส่งอุณหภูมิทุก 2 วินาที หายไปบ้างก็ไม่เป็นไร)
  • QoS 1 (At least once - ส่งอย่างน้อยหนึ่งครั้ง / การันตีถึงแน่นอน):
  • - ผู้ส่งจะรอจนกว่าจะได้รับข้อความตอบรับ PUBACK หากไม่ได้รับในเวลาที่กำหนด จะส่งข้อความซ้ำอีกครั้ง
  • - *ข้อดี*: การันตีว่าข้อความจะไปถึงผู้รับ 100%
  • - *ข้อเสีย*: หากเน็ตกระตุกตอนส่งใบตอบรับ อาจทำให้ผู้รับได้รับข้อความซ้ำซ้อน (Duplicate messages) ได้
  • - *ความเหมาะสม*: ใช้กับงานส่งสถานะสวิตช์เปิด-ปิด หรือการแจ้งเตือนทั่วไป
  • QoS 2 (Exactly once - ส่งครั้งเดียวแน่นอน / ไม่หายและไม่ซ้ำ):
  • - มีการจับมือยืนยันข้อมูล 4 ขั้นตอน (Four-step Handshake: PUBLISH $\rightarrow$ PUBREC $\rightarrow$ PUBREL $\rightarrow$ PUBCOMP)
  • - *ข้อดี*: ปลอดภัยสูงสุด มั่นใจได้ 100% ว่าข้อความจะได้รับเพียงครั้งเดียวเท่านั้น ไม่หายและไม่ซ้ำซ้อน
  • - *ข้อเสีย*: มีความล่าช้า (Latency) สูงสุด และใช้ปริมาณแบนด์วิดท์มากที่สุด
  • - *ความเหมาะสม*: ใช้กับงานธุรกรรมการเงิน (Billing), ระบบล็อกประตูนิรภัย, หรือระบบควบคุมเครื่องจักรโรงงานที่ผิดพลาดไม่ได้เด็ดขาด
💡 สรุปเปรียบเทียบ QoS: สำหรับงาน IoT ด้านสิ่งแวดล้อมและเกษตรกรรมทั่วไป มักเลือกใช้ QoS 0 หรือ QoS 1 เพื่อความรวดเร็วและประหยัดทรัพยากรของบอร์ด

  • JSON คืออะไร (สไลด์ 10): รูปแบบข้อความมาตรฐานเปิด (Open Standard Text Format) ที่ใช้แลกเปลี่ยนข้อมูลระหว่างคอมพิวเตอร์ มีจุดเด่นคือ อ่านและเขียนเข้าใจได้ง่ายสำหรับมนุษย์ และโปรแกรมคอมพิวเตอร์สามารถแปลง (Parse/Serialize) ได้รวดเร็วมาก

  • - Value (ค่า): สามารถเป็นชนิดข้อมูลใดก็ได้ ได้แก่ String, Number, Boolean (true/false), Array, Object ย่อย หรือ null
  • - ตัวอย่างตามสไลด์ 10: `json { "name": "Messi", "age": 37, "isPlayer": true } `
  • 2. Array (แถวลำดับชุดข้อมูล - สไลด์ 11):
  • - บรรจุอยู่ภายในเครื่องหมายวงเล็บก้ามปูเหลี่ยม [ ]
  • - จัดเก็บชุดข้อมูลหลายค่าเรียงตามลำดับดัชนี (Index) คั่นแต่ละค่าด้วยเครื่องหมายจุลภาค ,
  • - ตัวอย่างตามสไลด์ 11: `json [ "Football", "Basketball", "Volleyball" ] `
💡 การประยุกต์ใช้ JSON ใน IoT: แทนที่จะส่งข้อมูลแยกกันหลาย Topic เราสามารถมัดรวมข้อมูลเซ็นเซอร์ทั้งหมดส่งใน Message เดียวได้ เช่น {"temp": 29.5, "humidity": 65.0, "soil": 780} ซึ่งช่วยประหยัดรอบการส่งข้อมูลและทำให้ข้อมูลทุกตัวมีเวลา (Timestamp) สัมพันธ์ตรงกัน
