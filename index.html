คำย่อและคำศัพท์เทคนิคในวิชา IoT (Master Acronyms Glossary)

ค้นหาและทบทวนความหมายของตัวย่อทุกตัวในหลักสูตร พร้อมคำแปลภาษาไทยและบริบทการใช้งาน

คำย่อ คำเต็มภาษาอังกฤษ (Full Name) ความหมายภาษาไทย คำอธิบายเสริมทางวิศวกรรม ปรากฏในบท
$\µ$F Microfarad ไมโครฟารัด (10⁻⁶ ฟารัด) หน่วยความจุที่พบบ่อยที่สุดในวงจรอิเล็กทรอนิกส์ บทที่ 06
A/D / ADC Analog-to-Digital Converter ตัวแปลงสัญญาณแอนะล็อกเป็นดิจิทัล วงจรแปลงแรงดันไฟฟ้าต่อเนื่องเป็นตัวเลข 10-bit (0-1023) บทที่ 09
AC / VAC Alternating Current / Volts Alternating Current ไฟฟ้ากระแสสลับ / โวลต์กระแสสลับ ไฟฟ้าที่มีทิศทางและขนาดเปลี่ยนแปลงเป็นรูปคลื่นไซน์ เช่น ไฟฟ้าตามบ้าน 220V 50Hz บทที่ 06
ADC / A/D Analog-to-Digital Converter ตัวแปลงสัญญาณแอนะล็อกเป็นดิจิทัล วงจรแปลงระดับแรงดันไฟฟ้าต่อเนื่อง (0-3.3V) ให้เป็นค่าตัวเลขดิจิทัล 10-bit (0-1023) หรือ 12-bit (0-4095) บทที่ 08
AO Analog Output ขาเอาต์พุตแอนะล็อกของเซ็นเซอร์ ส่งระดับแรงดันไฟต่อเนื่องตามค่าทางกายภาพที่วัดได้ บทที่ 09
API Application Programming Interface ส่วนต่อประสานโปรแกรมประยุกต์ ช่องทางให้โปรแกรมภายนอกหรือหน้าเว็บดึงข้อมูลจาก Broker ไปแสดงผล บทที่ 10
Ah Ampere-hour แอมแปร์-ชั่วโมง หน่วยวัดความจุพลังงานไฟฟ้าของแบตเตอรี่ (จ่ายกระแส 1 แอมแปร์ได้นานกี่ชั่วโมง) บทที่ 06
Auth Token Authentication Token โทเคนยืนยันตัวตนความปลอดภัย สตริงตัวอักษรรหัสลับยาว 32 ตัวอักษร ทำหน้าที่เสมือนกุญแจส่วนตัวของอุปกรณ์ในการสื่อสารกับเซิร์ฟเวอร์ บทที่ 05
BLE Bluetooth Low Energy บลูทูธพลังงานต่ำ โปรโตคอลสื่อสารระยะสั้นกินไฟน้อยมาก เหมาะกับ Smart Wearable และเซ็นเซอร์พกพา บทที่ 01
C Capacitor / Capacitance ตัวเก็บประจุ / ค่าความจุไฟฟ้า อุปกรณ์กักเก็บและคายประจุไฟฟ้า หน่วยวัดเป็น ฟารัด (Farad: F) บทที่ 06
CCTV Closed-Circuit Television กล้องโทรทัศน์วงจรปิด ระบบส่งสัญญาณภาพจากกล้องไปยังจุดรับชมเฉพาะจุดเพื่อการรักษาความปลอดภัยและจราจร บทที่ 01
COM Communication Port พอร์ตสื่อสารอนุกรมเสมือนบนระบบปฏิบัติการ เช่น COM3, COM4 ที่ Windows กำหนดให้กับบอร์ดที่เสียบ USB บทที่ 07
DAC / D/A Digital-to-Analog Converter ตัวแปลงสัญญาณดิจิทัลเป็นแอนะล็อก วงจรสร้างแรงดันไฟฟ้าแอนะล็อกของจริงจากค่าตัวเลขดิจิทัล บทที่ 08
DC / VDC Direct Current / Volts Direct Current ไฟฟ้ากระแสตรง / โวลต์กระแสตรง ไฟฟ้าที่มีทิศทางการไหลขั้วเดียวสม่ำเสมอ เช่น แบตเตอรี่ ถ่านไฟฉาย วงจรไมโครคอนโทรลเลอร์ บทที่ 06
DHT11 Digital Humidity and Temperature Sensor Model 11 เซ็นเซอร์วัดอุณหภูมิและความชื้นสัมพัทธ์แบบดิจิทัลรุ่น 11 เซ็นเซอร์ยอดนิยมส่งข้อมูลดิจิทัลทางสายเดี่ยว (Single-wire serial) บทที่ 09
DO Digital Output ขาเอาต์พุตดิจิทัลของเซ็นเซอร์ ส่งลอจิก 0 หรือ 1 ตามเกณฑ์เปรียบเทียบแรงดันของชิป LM393 บทที่ 09
ESP32 Espressif Systems 32-bit Dual-core Microcontroller ไมโครคอนโทรลเลอร์ทรงพลัง 2 คอร์ พร้อม Wi-Fi และ Bluetooth ในตัว บอร์ดประมวลผลหลักที่ใช้ในการทดลองบทนี้ (NodeMCU ESP32 30/38 pins) บทที่ 08
ESP8266 Espressif Systems SoC model 8266 ชิปประมวลผล 32-bit พร้อม Wi-Fi ในตัวของบริษัท Espressif หัวใจประมวลผลหลักของ NodeMCU ทำงานที่ความถี่ 80/160 MHz บทที่ 07
Echo Echo ขาสัญญาณสะท้อนกลับ ขาเอาต์พุตของเซ็นเซอร์อัลตราโซนิก ส่งพัลส์ความยาวเวลาเท่ากับเวลาที่คลื่นเสียงสะท้อนกลับมา บทที่ 03
F Farad ฟารัด หน่วยวัดความจุประจุไฟฟ้าตามระบบสากล SI บทที่ 06
FSR Force Sensitive Resistor ตัวต้านทานแปรผันตามแรงกด แผ่นเซ็นเซอร์ที่ความต้านทานจะลดลงเมื่อมีแรงกดกระทำ บทที่ 02
GND Ground กราวด์ / จุดอ้างอิงแรงดันศูนย์โวลต์ (0V) ขั้วลบของระบบไฟฟ้า วงจรจะทำงานได้ต้องต่อกราวด์ร่วมกัน บทที่ 03
GPIO General-Purpose Input/Output ขาอินพุต/เอาต์พุตอเนกประสงค์ ขาพอร์ตดิจิทัลบนบอร์ด เช่น D0-D8 (GPIO16, GPIO5, GPIO4 ฯลฯ) บทที่ 07
GPS Global Positioning System ระบบระบุพิกัดตำแหน่งบนโลกผ่านดาวเทียม ใช้ระบุละติจูดและลองจิจูดของอุปกรณ์ เช่น รถยนต์อัจฉริยะ โดรน หรือสมาร์ตโฟน บทที่ 01
GUI Graphical User Interface ส่วนต่อประสานกราฟิกกับผู้ใช้ เช่น หน้าจอโปรแกรม MQTT Explorer ที่แสดง Topic Tree เป็นรูปภาพต้นไม้ บทที่ 10
I/O Input / Output สัญญาณขาเข้าและขาออก ช่องทางติดต่อสื่อสารระหว่างไมโครคอนโทรลเลอร์กับโลกภายนอก บทที่ 02
IC Integrated Circuit วงจรรวม / วงจรเบ็ดเสร็จ (ไอซี) ชิปซิลิคอนขนาดเล็กที่รวมชิ้นส่วนวงจรอิเล็กทรอนิกส์หลายล้านตัวไว้ภายใน บทที่ 06
ID Identification / Identifier รหัสระบุตัวตน เช่น Template ID สำหรับอ้างอิงแม่แบบอุปกรณ์ในระบบคลาวด์ บทที่ 05
IDE Integrated Development Environment สภาพแวดล้อมสำหรับการพัฒนาแบบเบ็ดเสร็จ โปรแกรมสำหรับเขียน ทดสอบ และคอมไพล์โค้ดโปรแกรม บทที่ 02
IO / GPIO Input / Output / General-Purpose Input/Output ขาอินพุต/เอาต์พุตอเนกประสงค์ พอร์ตติดต่อของ KidBright เช่น ขา IO18 และ ขา IO19 บทที่ 03
IR Infrared รังสีอินฟราเรด คลื่นแม่เหล็กไฟฟ้าความยาวคลื่นยาวกว่าแสงสีแดง ใช้ในรีโมทและเซ็นเซอร์ตรวจจับวัตถุ บทที่ 02
IoT Internet of Things อินเทอร์เน็ตของสรรพสิ่ง เครือข่ายของสิ่งของหรืออุปกรณ์ที่ฝังเซ็นเซอร์และซอฟต์แวร์ให้สามารถแลกเปลี่ยนข้อมูลกันผ่านอินเทอร์เน็ตได้อัตโนมัติ บทที่ 01
JSON JavaScript Object Notation รูปแบบข้อมูลมาตรฐานที่ใช้ระบุลิงก์ Index ติดตั้งบอร์ด ไฟล์ package_esp8266com_index.json ที่ใส่ใน Preferences บทที่ 07
KB KidBright บอร์ดสมองกลฝังตัวเพื่อการศึกษา พัฒนาโดย NECTEC ใช้ชิปหลัก ESP32 บอร์ดไมโครคอนโทรลเลอร์พร้อมหน้าจอ LED 16x8 ปุ่มกด ลำโพง และเซ็นเซอร์วัดแสง/อุณหภูมิในตัว บทที่ 02
LDR Light Dependent Resistor ตัวต้านทานแปรค่าตามความเข้มแสง / โฟโตรีซิสเตอร์ สารกึ่งตัวนำ CdS ที่ความต้านทานจะลดลงเมื่อได้รับแสงสว่าง บทที่ 09
LED Light-Emitting Diode ไดโอดเปล่งแสง อุปกรณ์ให้แสงสว่าง หน้าจอ Matrix 16x8 บน KidBright บทที่ 02
LPG Liquefied Petroleum Gas ก๊าซปิโตรเลียมเหลว / ก๊าซหุงต้ม ก๊าซเชื้อเพลิงที่ประกอบด้วยโพรเพนและบิวเทน ไวไฟสูง บทที่ 02
M2M Machine-to-Machine การสื่อสารระหว่างเครื่องจักรกับเครื่องจักร การแลกเปลี่ยนข้อมูลโดยตรงระหว่างอุปกรณ์ปลายทางโดยไม่มีมนุษย์เข้ามาแทรกแซง บทที่ 01
MCU Microcontroller Unit หน่วยควบคุมขนาดเล็ก / ไมโครคอนโทรลเลอร์ ไอซีที่รวม CPU, RAM, ROM, I/O ไว้ในตัว เช่น ESP32, ESP8266, Arduino บทที่ 01
MQTT Message Queuing Telemetry Transport โปรโตคอลการสื่อสารข้อมูลระยะไกลแบบส่งต่อข้อความ (สถาปัตยกรรม Publish/Subscribe) โปรโตคอลมาตรฐานสากลสำหรับ IoT น้ำหนักเบามาก กินแบนด์วิดท์ต่ำ ออกแบบโดย Andy Stanford-Clark และ Arlen Nipper บทที่ 10
NC Normally Closed หน้าสัมผัสปกติปิด สภาวะปกติวงจรปิด (ไฟไหลผ่านตลอด) เมื่อรีเลย์ทำงานหน้าสัมผัสจะถูกดึงแยกออก วงจรจะถูกตัดขาด บทที่ 09
NECTEC National Electronics and Computer Technology Center ศูนย์เทคโนโลยีอิเล็กทรอนิกส์และคอมพิวเตอร์แห่งชาติ หน่วยงานวิจัยและพัฒนาของไทยผู้ให้กำเนิดบอร์ด KidBright บทที่ 02
NFC Near Field Communication การสื่อสารไร้สายระยะใกล้มาก ระยะ 4-10 ซม. ใช้ในการแตะจ่ายเงินหรือจับคู่อุปกรณ์อย่างรวดเร็ว บทที่ 01
NO Normally Open หน้าสัมผัสปกติเปิด สภาวะปกติวงจรเปิด (ไฟไม่ผ่าน) เมื่อรีเลย์ทำงานหน้าสัมผัสจะดูดติดกัน ไฟจึงจะไหลผ่าน บทที่ 09
NodeMCU Node Microcontroller Unit บอร์ดพัฒนาอุปกรณ์ IoT ตระกูล ESP8266 แบบ Open-source บอร์ดพัฒนาที่รวบรวมชิป ESP8266, ภาคจ่ายไฟ 3.3V, และชิปแปลง USB-to-UART ไว้บนบอร์ดเดียว บทที่ 07
OS Operating System ระบบปฏิบัติการ ซอฟต์แวร์ระบบ เช่น Linux, Windows, RTOS ที่ใช้จัดการทรัพยากรของอุปกรณ์ บทที่ 01
PIR Passive Infrared Sensor เซ็นเซอร์ตรวจจับรังสีอินฟราเรดจากความร้อนของสิ่งมีชีวิต ใช้ตรวจจับคนหรือสัตว์ที่เดินผ่านในระยะ 3-7 เมตร บทที่ 02
PWM Pulse Width Modulation การมอดูเลตความกว้างสัญญาณพัลส์ เทคนิคการเปิด-ปิดสัญญาณดิจิทัลอย่างรวดเร็วเพื่อจำลองระดับแรงดันแอนะล็อก เช่น หรี่ไฟ LED บทที่ 08
QoS Quality of Service ระดับการรับประกันคุณภาพในการส่งมอบข้อความ กลไกใน MQTT ที่กำหนดความน่าเชื่อถือของการส่งข้อมูล มี 3 ระดับ (QoS 0, QoS 1, QoS 2) บทที่ 10
R Resistor / Resistance ตัวต้านทาน / ค่าความต้านทานไฟฟ้า อุปกรณ์จำกัดปริมาณกระแสไฟฟ้า หน่วยวัดเป็น โอห์ม (Ohm: Ω (โอห์ม)) บทที่ 06
RF Radio Frequency ความถี่วิทยุ ย่านความถี่คลื่นแม่เหล็กไฟฟ้าสำหรับการสื่อสารไร้สาย บทที่ 06
RFID Radio-Frequency Identification การระบุเอกลักษณ์ด้วยคลื่นความถี่วิทยุ ใช้แท็กคลื่นวิทยุติดสินค้าเพื่อเช็กสต็อกอัตโนมัติใน Smart Retail บทที่ 01
RH Relative Humidity ความชื้นสัมพัทธ์ในอากาศ ร้อยละของปริมาณไอน้ำในอากาศเทียบกับปริมาณไอน้ำอิ่มตัวที่อุณหภูมินั้น บทที่ 09
RTC Real-Time Clock นาฬิกาบอกเวลาจริง วงจรนับเวลา วินาที นาที ชั่วโมง วันที่ บนตัวบอร์ด KidBright บทที่ 02
SBC Single-Board Computer คอมพิวเตอร์บอร์ดเดี่ยว คอมพิวเตอร์ที่รวมทุกวงจรไว้บนบอร์ดเดียว ติดตั้ง OS ตัวเต็มได้ เช่น Raspberry Pi บทที่ 01
SSL / TLS Secure Sockets Layer / Transport Layer Security โพรโทคอลความปลอดภัยสำหรับการเข้ารหัสข้อมูลบนเครือข่าย ใช้รักษาความปลอดภัยเมื่อเชื่อมต่อไปยังพอร์ต 8883 ของ HiveMQ Cloud บทที่ 10
SW Switch สวิตช์ไฟฟ้า อุปกรณ์ตัดต่อวงจรด้วยมือ เช่น ไมโครสวิตช์ปุ่มกด บทที่ 08
TCP/IP Transmission Control Protocol / Internet Protocol ชุดโปรโตคอลมาตรฐานสำหรับการสื่อสารบนเครือข่ายอินเทอร์เน็ต โปรโตคอลเลเยอร์เครือข่ายที่รับประกันความถูกต้องของการส่งแพ็กเก็ตข้อมูลที่ MQTT ทำงานอยู่ด้านบน บทที่ 10
Trig Trigger ขาสัญญาณกระตุ้น ขาอินพุตของเซ็นเซอร์อัลตราโซนิก ใช้รับสัญญาณพัลส์จากไมโครคอนโทรลเลอร์เพื่อเริ่มส่งคลื่นเสียง บทที่ 03
UART Universal Asynchronous Receiver-Transmitter วงจรสื่อสารอนุกรมแบบอะซิงโครนัส โปรโตคอลสื่อสารแบบ Serial ใช้คุยระหว่างคอมพิวเตอร์กับบอร์ดผ่านขา TX/RX บทที่ 07
UI User Interface ส่วนต่อประสานกับผู้ใช้งาน หน้าจอ Dashboard และ Widgets บนสมาร์ตโฟนสำหรับให้ผู้ใช้สั่งงาน บทที่ 05
USB Universal Serial Bus พอร์ตเชื่อมต่อมาตรฐานสากล ช่องจ่ายไฟ 5V ที่สามารถควบคุมเปิด-ปิดได้บน KidBright บทที่ 02
V-Pin / VP Virtual Pin ขาดิจิทัลเสมือน / พอร์ตจำลองในซอฟต์แวร์ ช่องทางแลกเปลี่ยนข้อมูลระหว่างแอปพลิเคชัน Blynk กับบอร์ด เช่น V0, V1, V2 โดยไม่ต้องผูกกับขาฮาร์ดแวร์จริง บทที่ 05
V2X Vehicle-to-Everything การสื่อสารระหว่างยานพาหนะกับทุกสรรพสิ่ง รถยนต์คุยกับรถคันอื่น (V2V), คุยกับโครงสร้างพื้นฐานถนน (V2I), คุยกับคนเดินเท้า (V2P) บทที่ 01
VCC Voltage Common Collector ขั้วต่อแหล่งจ่ายแรงดันไฟฟ้าบวกของวงจร ไฟเลี้ยงบอร์ด/เซ็นเซอร์ ในการทดลองนี้ต่อเข้ากับแรงดัน 3.3V หรือ 5V บทที่ 03
VR Variable Resistor / Potentiometer ตัวต้านทานปรับค่าได้ ตัวต้านทานที่มีปุ่มหมุนปรับค่าความต้านทานได้อย่างต่อเนื่อง บทที่ 06
Vin Voltage Input ช่องรับแรงดันไฟเลี้ยงจากภายนอก รับไฟบวก 5V - 12V เข้าสู่วงจรควบคุมแรงดัน LDO บนบอร์ด บทที่ 08
WSN Wireless Sensor Network เครือข่ายเซ็นเซอร์ไร้สาย กลุ่มเซ็นเซอร์กระจายตัวเก็บข้อมูลสภาพแวดล้อม (ความชื้น อุณหภูมิ แสง) และส่งผ่านคลื่นวิทยุ บทที่ 01
Wi-Fi Wireless Fidelity การเชื่อมต่อเครือข่ายท้องถิ่นแบบไร้สาย (IEEE 802.11) ช่องทางการสื่อสารไร้สายที่บอร์ด KidBright ใช้เชื่อมต่ออินเทอร์เน็ตเข้าสู่ Blynk Cloud บทที่ 05

Introduction to IoT (บทนำอินเทอร์เน็ตของสรรพสิ่ง)

ความหมายของ IoT, สถาปัตยกรรม 3 ระดับ, การประยุกต์ใช้งาน, บอร์ดไมโครคอนโทรลเลอร์ และการจำแนกอุปกรณ์

คำย่อและคำเต็มในบทนี้ (Acronyms & Vocabulary)

คำย่อ คำเต็มภาษาอังกฤษ (Full Name) ความหมายภาษาไทย คำอธิบายเสริมในบทเรียน
IoT Internet of Things อินเทอร์เน็ตของสรรพสิ่ง เครือข่ายของสิ่งของหรืออุปกรณ์ที่ฝังเซ็นเซอร์และซอฟต์แวร์ให้สามารถแลกเปลี่ยนข้อมูลกันผ่านอินเทอร์เน็ตได้อัตโนมัติ
M2M Machine-to-Machine การสื่อสารระหว่างเครื่องจักรกับเครื่องจักร การแลกเปลี่ยนข้อมูลโดยตรงระหว่างอุปกรณ์ปลายทางโดยไม่มีมนุษย์เข้ามาแทรกแซง
WSN Wireless Sensor Network เครือข่ายเซ็นเซอร์ไร้สาย กลุ่มเซ็นเซอร์กระจายตัวเก็บข้อมูลสภาพแวดล้อม (ความชื้น อุณหภูมิ แสง) และส่งผ่านคลื่นวิทยุ
CCTV Closed-Circuit Television กล้องโทรทัศน์วงจรปิด ระบบส่งสัญญาณภาพจากกล้องไปยังจุดรับชมเฉพาะจุดเพื่อการรักษาความปลอดภัยและจราจร
GPS Global Positioning System ระบบระบุพิกัดตำแหน่งบนโลกผ่านดาวเทียม ใช้ระบุละติจูดและลองจิจูดของอุปกรณ์ เช่น รถยนต์อัจฉริยะ โดรน หรือสมาร์ตโฟน
RFID Radio-Frequency Identification การระบุเอกลักษณ์ด้วยคลื่นความถี่วิทยุ ใช้แท็กคลื่นวิทยุติดสินค้าเพื่อเช็กสต็อกอัตโนมัติใน Smart Retail
NFC Near Field Communication การสื่อสารไร้สายระยะใกล้มาก ระยะ 4-10 ซม. ใช้ในการแตะจ่ายเงินหรือจับคู่อุปกรณ์อย่างรวดเร็ว
BLE Bluetooth Low Energy บลูทูธพลังงานต่ำ โปรโตคอลสื่อสารระยะสั้นกินไฟน้อยมาก เหมาะกับ Smart Wearable และเซ็นเซอร์พกพา
OS Operating System ระบบปฏิบัติการ ซอฟต์แวร์ระบบ เช่น Linux, Windows, RTOS ที่ใช้จัดการทรัพยากรของอุปกรณ์
MCU Microcontroller Unit หน่วยควบคุมขนาดเล็ก / ไมโครคอนโทรลเลอร์ ไอซีที่รวม CPU, RAM, ROM, I/O ไว้ในตัว เช่น ESP32, ESP8266, Arduino
SBC Single-Board Computer คอมพิวเตอร์บอร์ดเดี่ยว คอมพิวเตอร์ที่รวมทุกวงจรไว้บนบอร์ดเดียว ติดตั้ง OS ตัวเต็มได้ เช่น Raspberry Pi
V2X Vehicle-to-Everything การสื่อสารระหว่างยานพาหนะกับทุกสรรพสิ่ง รถยนต์คุยกับรถคันอื่น (V2V), คุยกับโครงสร้างพื้นฐานถนน (V2I), คุยกับคนเดินเท้า (V2P)

  • ไมโครคอนโทรลเลอร์และเซ็นเซอร์มีราคาถูกลงอย่างมากแต่ประสิทธิภาพสูงขึ้น (เช่น ESP32 ราคาไม่ถึงร้อยบาท)

องค์ประกอบ 3 ส่วนหลักของระบบ IoT (สถาปัตยกรรม 3 ชั้น):
  • 1. End Nodes (Edge Devices / ปลายทาง): อุปกรณ์เซ็นเซอร์ (รับค่าจากสิ่งแวดล้อม) และอุปกรณ์ขับเคลื่อน (Actuators เช่น มอเตอร์ วาล์ว รีเลย์ หลอดไฟ) ควบคุมโดยไมโครคอนโทรลเลอร์
  • 2. Connectivity (ระบบเชื่อมต่อ): ช่องทางการสื่อสาร ทั้งระยะใกล้ (Bluetooth, BLE, Zigbee, Wi-Fi) และระยะไกล (Cellular 4G/5G, NB-IoT, LoRaWAN) ทำหน้าที่ส่งต่อข้อมูล
  • 3. Central Servers / Cloud (เซิร์ฟเวอร์กลาง): ทำหน้าที่รวบรวมข้อมูล วิเคราะห์ ประมวลผล จัดเก็บลงฐานข้อมูล และแสดงผลหน้าแดชบอร์ด (Dashboard) ให้ผู้ใช้ดูหรือสั่งการย้อนกลับ

const int RELAY_PUMP_PIN = 23;        // ขาควบคุมรีเลย์ปั๊มน้ำ

void processFarmAutomation(float temperature, int soilMoisture) {
    Serial.print("tok-string">"Current Temp: "); Serial.print(temperature); Serial.println("tok-string">" C");
    Serial.print("tok-string">"Soil Moisture: "); Serial.println(soilMoisture);

    // ตรวจสอบเงื่อนไขความชื้นในดินและอุณหภูมิ

Arduino C++ โครงสร้างพื้นฐานโปรแกรมภาษา C++ บนบอร์ด KidBright / ESP32
ฟังก์ชัน setup() ทำงานรอบเดียว และ loop() ทำงานวนซ้ำตลอดเวลา
// กำหนดขาพินใช้งาน
const int LED_PIN = 2;       // ขา LED บนบอร์ด (GPIO2)
const int SWITCH_PIN = 16;   // ขาสวิตช์ปุ่มกด Switch 1

void setup() {
    // 1. ตั้งค่าความเร็วพอร์ตสื่อสาร Serial เพื่อส่งข้อความ Debug ไปยังคอมพิวเตอร์
    Serial.begin(115200);
    Serial.println("tok-string">"KidBright / ESP32 Ready!");

    // 2. กำหนดโหมดการทำงานของขาพิน
    pinMode(LED_PIN, OUTPUT);           // ขา LED เป็น Digital Output
    pinMode(SWITCH_PIN, INPUT_PULLUP);  // ขาสวิตช์เป็น Digital Input พร้อมเปิดตัวต้านทาน Pull-up
}

void loop() {
    // อ่านค่าสถานะปุ่มกด (0 = กดปุ่ม, 1 = ปล่อยปุ่ม)
    int btnState = digitalRead(SWITCH_PIN);

    if (btnState == LOW) {
        // เมื่อกดปุ่ม สั่งเปิดไฟ LED
        digitalWrite(LED_PIN, HIGH);
        Serial.println("tok-string">"Button Pressed -> LED ON");
    } else {
        // เมื่อปล่อยปุ่ม สั่งปิดไฟ LED
        digitalWrite(LED_PIN, LOW);
    }

    delay(50); // หน่วงเวลาสั้น ๆ เพื่อลดภาระการประมวลผล
}

หลักการสะท้อนของคลื่นเสียงความถี่สูง (Ultrasonic Wave Echo Principle):
  • หูมนุษย์ได้ยินเสียงในช่วง 20 Hz - 20,000 Hz (20 kHz) แต่คลื่นอัลตราโซนิกจะมีความถี่สูงกว่า 20 kHz โดยเซ็นเซอร์ HC-SR04 ทำงานที่ความถี่มาตรฐาน 40,000 Hz (40 kHz)
  • บอร์ด KidBright ส่งพัลส์ลอจิก HIGH ไปยังขา Trig กว้างอย่างน้อย 10 ไมโครวินาที (10 ไมโครวินาที (10 µs))
  • ตัวส่งสัญญาณ (Transmitter รูปตัว T) จะยิงคลื่นอัลตราโซนิกความถี่ 40 kHz ออกไปเป็นชุด 8 ลูก (Sonic Burst)
  • คลื่นเสียงเดินทางผ่านอากาศไปกระทบกับวัตถุกีดขวางข้างหน้า แล้วสะท้อนกลับมายังตัวรับสัญญาณ (Receiver รูปตัว R)
  • เมื่อตัวรับตรวจพบคลื่นสะท้อน ขา Echo จะสร้างสัญญาณพัลส์ HIGH ขึ้นมา โดยความกว้างของช่วงเวลา HIGH นี้ จะมีค่าเท่ากับ 'ระยะเวลาทั้งหมดที่คลื่นเสียงใช้เดินทางไปและกลับ'

ขาเชื่อมต่อ: VCC (3.3-5V), GND, Trig, Echo
Arduino C++ การเขียนโปรแกรมวัดระยะทางด้วยเซ็นเซอร์ Ultrasonic (HC-SR04)
การยิงพัลส์ขา Trig, จับเวลาสะท้อนขา Echo ด้วย pulseIn(), และคำนวณระยะทาง
// กำหนดขาเชื่อมต่อเซ็นเซอร์ HC-SR04 กับบอร์ด KidBright / ESP32
const int TRIG_PIN = 19;    // ขา Trig (Trigger) สั่งยิงคลื่นเสียง
const int ECHO_PIN = 18;    // ขา Echo รับคลื่นเสียงสะท้อนกลับ
const int BUZZER_PIN = 23;  // ขาต่อ Buzzer แจ้งเตือน

void setup() {
    Serial.begin(115200);
    pinMode(TRIG_PIN, OUTPUT);
    pinMode(ECHO_PIN, INPUT);
    pinMode(BUZZER_PIN, OUTPUT);
}

void loop() {
    // 1. เคลียร์สัญญาณขา Trig ให้เป็น LOW ก่อน
    digitalWrite(TRIG_PIN, LOW);
    delayMicroseconds(2);

    // 2. ส่งพัลส์ HIGH กว้าง 10 ไมโครวินาที เพื่อสั่งให้เซ็นเซอร์ยิงคลื่นเสียง 40 kHz
    digitalWrite(TRIG_PIN, HIGH);
    delayMicroseconds(10);
    digitalWrite(TRIG_PIN, LOW);

    // 3. ใช้ฟังก์ชัน pulseIn() จับเวลาที่ขา Echo เป็น HIGH (หน่วย: ไมโครวินาที µs)
    long duration = pulseIn(ECHO_PIN, HIGH);

    // 4. คำนวณระยะทาง (cm) = (เวลาเดินทางไป-กลับ x ความเร็วเสียง 0.0343 cm/µs) / 2
    // หรือสูตรย่อ: duration / 58.3
    float distance = (duration * 0.0343) / 2.0;

    // 5. แสดงผลระยะทางออกทาง Serial Monitor
    Serial.print("tok-string">"Distance: ");
    Serial.print(distance);
    Serial.println("tok-string">" cm");

    // ตัวอย่างประยุกต์ระบบถอยจอดรถ: ถ้าระยะน้อยกว่า 10 ซม. ให้ส่งเสียงเตือน
    if (distance > 0 && distance < 10.0) {
        digitalWrite(BUZZER_PIN, HIGH); // ร้องเตือน
    } else {
        digitalWrite(BUZZER_PIN, LOW);  // หยุดร้อง
    }

    delay(200); // หน่วงเวลา 200 ms ก่อนเริ่มวัดรอบถัดไป
}

BLYNK_WRITE(V1) {

    } else {
        digitalWrite(RELAY_PIN, HIGH); // 3.3V เพื่อสั่งรีเลย์ตัดไฟ
        Serial.println("tok-string">"Blynk App: Relay OFF");

void setup() {
    Serial.begin(115200);
    pinMode(RELAY_PIN, OUTPUT);
    digitalWrite(RELAY_PIN, HIGH); // ปิดรีเลย์ไว้ก่อนเป็นค่าเริ่มต้น
    
    // เชื่อมต่อ Wi-Fi และเซิร์ฟเวอร์ Blynk Cloud
    Blynk.begin(BLYNK_AUTH_TOKEN, ssid, pass);
}

void loop() {
    Blynk.run(); // ต้องเรียกฟังก์ชันนี้ใน loop ตลอดเวลาเพื่อจัดการการรับ-ส่งข้อมูล
    
    // ตัวอย่างการส่งค่าอุณหภูมิขึ้นไปแสดงบนหน้าปัด Gauge (Virtual Pin V2)
    static unsigned long lastSend = 0;
    if (millis() - lastSend > 2000) { // ส่งข้อมูลทุก ๆ 2 วินาที
        float currentTemp = 28.5;     // สมมติค่าอุณหภูมิที่อ่านจากเซ็นเซอร์
        Blynk.virtualWrite(V2, currentTemp);
        lastSend = millis();
    }
}

คำย่อ คำเต็มภาษาอังกฤษ (Full Name) ความหมายภาษาไทย คำอธิบายเสริมในบทเรียน
R Resistor / Resistance ตัวต้านทาน / ค่าความต้านทานไฟฟ้า อุปกรณ์จำกัดปริมาณกระแสไฟฟ้า หน่วยวัดเป็น โอห์ม (Ohm: Ω (โอห์ม))

DC / VDC Direct Current / Volts Direct Current ไฟฟ้ากระแสตรง / โวลต์กระแสตรง ไฟฟ้าที่มีทิศทางการไหลขั้วเดียวสม่ำเสมอ เช่น แบตเตอรี่ ถ่านไฟฉาย วงจรไมโครคอนโทรลเลอร์
AC / VAC Alternating Current / Volts Alternating Current ไฟฟ้ากระแสสลับ / โวลต์กระแสสลับ ไฟฟ้าที่มีทิศทางและขนาดเปลี่ยนแปลงเป็นรูปคลื่นไซน์ เช่น ไฟฟ้าตามบ้าน 220V 50Hz
C Capacitor / Capacitance ตัวเก็บประจุ / ค่าความจุไฟฟ้า อุปกรณ์กักเก็บและคายประจุไฟฟ้า หน่วยวัดเป็น ฟารัด (Farad: F)
F Farad ฟารัด หน่วยวัดความจุประจุไฟฟ้าตามระบบสากล SI
$\µ$F Microfarad ไมโครฟารัด (10⁻⁶ ฟารัด) หน่วยความจุที่พบบ่อยที่สุดในวงจรอิเล็กทรอนิกส์

IC Integrated Circuit วงจรรวม / วงจรเบ็ดเสร็จ (ไอซี) ชิปซิลิคอนขนาดเล็กที่รวมชิ้นส่วนวงจรอิเล็กทรอนิกส์หลายล้านตัวไว้ภายใน

Arduino C++ การเขียนโค้ดไฟกะพริบ LED (Blink) และแก้ปัญหาสัญญาณสวิตช์กระดอน (Debounce)
การคำนวณความปลอดภัยทางไฟฟ้าและเขียนโปรแกรมลดสัญญาณรบกวนหน้าสัมผัสสวิตช์
// ตัวอย่างการต่อ LED ผ่านตัวต้านทาน 470 โอห์ม และอ่านสวิตช์แบบลดสัญญาณกระดอน
const int LED_PIN = 23;
const int BUTTON_PIN = 18;

int ledState = LOW;
int lastButtonState = HIGH;
unsigned long lastDebounceTime = 0;
const unsigned long DEBOUNCE_DELAY = 50; // หน่วงเวลาตรวจจับ 50 ms

void setup() {
    pinMode(LED_PIN, OUTPUT);
    pinMode(BUTTON_PIN, INPUT_PULLUP); // ใช้ Pull-up สวิตช์กดแล้วได้ลอจิก 0
}

void loop() {
    int reading = digitalRead(BUTTON_PIN);

    // ตรวจสอบการเปลี่ยนสถานะเพื่อเริ่มนับเวลา Debounce
    if (reading != lastButtonState) {
        lastDebounceTime = millis();
    }

    // หากสถานะนิ่งเกิน 50 ms จึงยอมรับว่าเป็นคำสั่งกดจริง ไม่ใช่ประกายไฟหน้าสัมผัส
    if ((millis() - lastDebounceTime) > DEBOUNCE_DELAY) {
        if (reading == LOW && lastButtonState == HIGH) {
            // สลับสถานะหลอดไฟ LED (Toggle)
            ledState = !ledState;
            digitalWrite(LED_PIN, ledState);
        }
    }

    lastButtonState = reading;
}

การแปลงขา D1/D2 เป็นหมายเลข GPIO สั่งงานไฟ LED และเชื่อมต่อ Wi-Fi Router
"tok-prep">#include <ESP8266WiFi.h>

// บน NodeMCU ต้องระวัง: ขา D1 คือ GPIO5, ขา D2 คือ GPIO4
const int LED_D1 = 5; // D1 (GPIO5)
const int LED_D2 = 4; // D2 (GPIO4)

const char* ssid = "tok-string">"MyHomeWiFi";
const char* password = "tok-string">"Password1234";

void setup() {
    Serial.begin(115200);
    delay(10);
    Serial.println("tok-string">"\nStarting NodeMCU ESP8266...");

    pinMode(LED_D1, OUTPUT);
    pinMode(LED_D2, OUTPUT);

    // เริ่มการเชื่อมต่อ Wi-Fi
    WiFi.begin(ssid, password);
    Serial.print("tok-string">"Connecting to Wi-Fi");

    while (WiFi.status() != WL_CONNECTED) {
        delay(500);
        Serial.print("tok-string">".");
        digitalWrite(LED_D1, !digitalRead(LED_D1)); // กะพริบไฟระหว่างรอเชื่อมต่อ
    }

    digitalWrite(LED_D1, HIGH); // ติดสว่างเมื่อต่อสำเร็จ
    Serial.println("tok-string">"\nWi-Fi Connected!");
    Serial.print("tok-string">"IP Address: ");
    Serial.println(WiFi.localIP()); // แสดงหมายเลข IP Address ที่ได้รับจาก Router
}

void loop() {
    // กะพริบไฟ LED ขา D2 ทุก 1 วินาที
    digitalWrite(LED_D2, HIGH);
    delay(1000);
    digitalWrite(LED_D2, LOW);
    delay(1000);
}

Arduino C++ การอ่านค่าแอนะล็อก ADC และสร้างสัญญาณ PWM หรี่ไฟ LED
การอ่าน analogRead() 10 บิต (0-1023), คำนวณเป็นแรงดันจริง, และสร้างสัญญาณ PWM
const int POT_PIN = 34;     // ขาต่อตัวต้านทานปรับค่าได้ (ADC1_CH6)
const int LED_PWM_PIN = 23; // ขาต่อ LED สำหรับหรี่ความสว่าง

// กำหนดคุณสมบัติ PWM ของ ESP32
const int PWM_FREQ = 5000;    // ความถี่ 5,000 Hz (5 kHz)
const int PWM_CHANNEL = 0;    // ช่องสัญญาณ PWM แชนแนล 0
const int PWM_RESOLUTION = 8; // ความละเอียด 8 บิต (ปรับค่าได้ 0 - 255)

void setup() {
    Serial.begin(115200);

    // ตั้งค่าช่องสัญญาณ PWM สำหรับ ESP32
    ledcSetup(PWM_CHANNEL, PWM_FREQ, PWM_RESOLUTION);
    ledcAttachPin(LED_PWM_PIN, PWM_CHANNEL);
}

void loop() {
    // 1. อ่านค่าแอนะล็อก (0 ถึง 1023 บนระบบ 10 บิต)
    int adcValue = analogRead(POT_PIN);

    // 2. คำนวณแปลงค่า ADC เป็นแรงดันไฟฟ้าจริง (โวลต์: V)
    float voltage = (adcValue / 1023.0) * 3.3;

    // 3. ทำการ Map ช่วงค่าจาก 0-1023 ให้ตรงกับความละเอียด PWM 8 บิต (0-255)
    int dutyCycle = map(adcValue, 0, 1023, 0, 255);

    // 4. สั่งขับสัญญาณ PWM หรี่ความสว่างตามการหมุนแกนตัวต้านทาน
    ledcWrite(PWM_CHANNEL, dutyCycle);

    // 5. แสดงผลข้อมูลทาง Serial Monitor
    Serial.print("tok-string">"ADC: "); Serial.print(adcValue);
    Serial.print("tok-string">" | Voltage: "); Serial.print(voltage); Serial.print("tok-string">" V");
    Serial.print("tok-string">" | Duty: "); Serial.print(dutyCycle); Serial.println("tok-string">" / 255");

    delay(100);
}

    pinMode(PUMP_RELAY, OUTPUT);
    digitalWrite(PUMP_RELAY, HIGH); // Active LOW: ค่าเริ่มต้นปิดรีเลย์

void loop() {

    int soilValue = analogRead(SOIL_PIN);

    Serial.print("tok-string">"LDR: "); Serial.print(ldrValue);
    Serial.print("tok-string">" | Soil: "); Serial.println(soilValue);

    // ตรวจสอบความสว่าง: ถ้าค่า LDR < 300 (ที่มืด) ให้เปิดไฟถนน
    if (ldrValue < 300) {

        Serial.println("tok-string">"-> สภาพแวดล้อมมืด: เปิดไฟถนนอัตโนมัติ");
    } else {
        digitalWrite(LIGHT_LED, LOW);
    }

    } else {
        digitalWrite(PUMP_RELAY, HIGH); // ปิดปั๊มน้ำ
    }

    delay(1000);
}

สไลด์ 1 - 4 สไลด์ 1 - 4: ความหมายและสถาปัตยกรรมของโปรโตคอล MQTT (Publish/Subscribe)
จุดเด่นที่ทำให้ MQTT เป็นหัวใจของ IoT:
  • น้ำหนักเบามาก (Lightweight): ตัวหัวเรื่องของข้อความ (Packet Header) มีขนาดเริ่มต้นเพียง 2 ไบต์ (2 Bytes) เท่านั้น ต่างจาก HTTP ที่มีขนาด Header หลายร้อยไบต์
  • ประหยัดแบนด์วิดท์ (Low Bandwidth): เหมาะอย่างยิ่งสำหรับเครือข่ายที่มีความเร็วต่ำ เช่น ซิมการ์ด 2G/3G/4G หรือสัญญาณมือถือในพื้นที่ชนบท
  • กินพลังงานต่ำ (Low Power Consumption): เหมาะสำหรับอุปกรณ์ End Nodes ที่ต้องเปิดทำงานด้วยพลังงานจากแบตเตอรี่หรือโซลาร์เซลล์
สไลด์ที่ 1 ดูภาพขยาย
3 บทบาทหลักในระบบ MQTT (สไลด์ 3):
  • 1. Broker (แม่ข่ายตัวกลาง): ทำหน้าที่เป็นศูนย์กลางคอยรับข้อความทั้งหมดจากผู้ส่ง กรองหัวข้อ (Topic Filtering) และส่งต่อข้อความไปยังผู้รับที่ลงทะเบียนไว้
  • 2. Publisher (ผู้ส่งข้อมูล): อุปกรณ์หรือโปรแกรมที่สร้างข้อมูลและส่ง (Publish) ไปยังหัวข้อ (Topic) ที่ระบุบน Broker เช่น บอร์ด ESP32 อ่านค่าอุณหภูมิแล้วส่งขึ้นไป
  • 3. Subscriber (ผู้รับข้อมูล): อุปกรณ์หรือแอปพลิเคชันที่ลงทะเบียนขอรับข้อมูล (Subscribe) ในหัวข้อที่สนใจ เช่น หน้าเว็บ Dashboard หรือแอปพลิเคชันบนมือถือ
  • *ข้อได้เปรียบสูงสุด*: Publisher และ Subscriber ไม่จำเป็นต้องรู้จักกัน ไม่ต้องมี IP Address ของกันและกัน และไม่ต้องเปิดออนไลน์พร้อมกัน (Decoupled in Space and Time)

Arduino C++ โปรแกรม ESP32 + DHT11 + HiveMQ Cloud (โค้ดทางการ อ.ประธาน: esp32_dht11_hivemq.ino)
อ่านอุณหภูมิจาก DHT11 (GPIO4) Publish ไปยัง Topic 'Temp' ทุก 5 วินาที และ Subscribe รับคำสั่งเปิด/ปิด LED Builtin (GPIO2) จาก Topic 'led/control'
"tok-prep">#include <WiFi.h>
"tok-prep">#include <WiFiClientSecure.h>
"tok-prep">#include <PubSubClient.h>
"tok-prep">#include <DHT.h>

// ===== การตั้งค่า WiFi =====
const char* WIFI_SSID = "tok-string">"YOUR_WIFI_NAME";
const char* WIFI_PASSWORD = "tok-string">"YOUR_WIFI_PASSWORD";

// ===== การตั้งค่า HiveMQ Cloud (TLS Port 8883) =====
const char* MQTT_HOST = "tok-string">"b95f18da0ac7417086f1155a81e190ca.s1.eu.hivemq.cloud";
const int MQTT_PORT = 8883;
const char* MQTT_USERNAME = "tok-string">"pcomejina";
const char* MQTT_PASSWORD = "tok-string">"YOUR_PASSWORD";

// หัวข้อ Topic (ต้องตรงกับไฟล์ Web Dashboard: Temp และ led/control)
const char* TEMP_TOPIC = "tok-string">"Temp";
const char* LED_CONTROL_TOPIC = "tok-string">"led/control";

// ===== ขาฮาร์ดแวร์ =====
"tok-prep">#define DHT_PIN 4      // ขา DATA ของ DHT11 ต่อเข้า GPIO 4
"tok-prep">#define DHT_TYPE DHT11 // ชนิดเซ็นเซอร์ DHT11
"tok-prep">#define LED_PIN 2      // ขาไฟ LED builtin บนบอร์ด ESP32 (GPIO 2)

DHT dht(DHT_PIN, DHT_TYPE);
WiFiClientSecure wifiClient;
PubSubClient mqttClient(wifiClient);

unsigned long lastPublishTime = 0;
const unsigned long publishInterval = 5000; // ส่งข้อมูลทุก 5 วินาที

void connectWiFi() {
  Serial.print("tok-string">"Connecting WiFi");
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print("tok-string">".");
  }

  Serial.println();
  Serial.print("tok-string">"WiFi connected, IP: ");
  Serial.println(WiFi.localIP());
}

// ฟังก์ชัน Callback: รับข้อความสั่งเปิด/ปิด LED จาก Web Dashboard
void handleMqttMessage(char* topic, byte* payload, unsigned int length) {
  String message = "tok-string">"";
  for (unsigned int i = 0; i < length; i++) {
    message += (char)payload[i];
  }
  message.trim();
  Serial.print("tok-string">"Message arrived ["); Serial.print(topic); Serial.print("tok-string">"]: "); Serial.println(message);

  if (String(topic) == LED_CONTROL_TOPIC) {
    if (message == "tok-string">"ON") {
      digitalWrite(LED_PIN, HIGH);
      Serial.println("tok-string">"LED Builtin: ON");
    } else if (message == "tok-string">"OFF") {
      digitalWrite(LED_PIN, LOW);
      Serial.println("tok-string">"LED Builtin: OFF");
    }
  }
}

void connectMQTT() {
  while (!mqttClient.connected()) {
    String clientId = "tok-string">"ESP32-DHT11-" + String((uint32_t)ESP.getEfuseMac(), HEX);
    Serial.print("tok-string">"Connecting MQTT...");

    if (mqttClient.connect(clientId.c_str(), MQTT_USERNAME, MQTT_PASSWORD)) {
      Serial.println("tok-string">"connected");
      mqttClient.subscribe(LED_CONTROL_TOPIC); // Subscribe หัวข้อควบคุมไฟ
      Serial.print("tok-string">"Subscribed: "); Serial.println(LED_CONTROL_TOPIC);
    } else {
      Serial.print("tok-string">"failed, rc="); Serial.print(mqttClient.state());
      Serial.println("tok-string">" try again in 3 seconds");
      delay(3000);
    }
  }
}

void publishTemperature() {
  float temperature = dht.readTemperature();
  if (isnan(temperature)) {
    Serial.println("tok-string">"Failed to read from DHT11");
    return;
  }

  char tempText[16];
  dtostrf(temperature, 4, 1, tempText);

  // Publish ค่าอุณหภูมิไปยัง Topic "Temp"
  mqttClient.publish(TEMP_TOPIC, tempText);
  Serial.print("tok-string">"Published temperature to "); Serial.print(TEMP_TOPIC);
  Serial.print("tok-string">": "); Serial.println(tempText);
}

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  digitalWrite(LED_PIN, LOW);

  dht.begin();
  connectWiFi();

  // ข้ามการตรวจ certificate chain สำหรับ HiveMQ Cloud แบบ TLS
  wifiClient.setInsecure();
  mqttClient.setServer(MQTT_HOST, MQTT_PORT);
  mqttClient.setCallback(handleMqttMessage);
}

void loop() {
  if (WiFi.status() != WL_CONNECTED) connectWiFi();
  if (!mqttClient.connected()) connectMQTT();
  mqttClient.loop();

  if (millis() - lastPublishTime >= publishInterval) {
    lastPublishTime = millis();
    publishTemperature();
  }
}
